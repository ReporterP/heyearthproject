# 02 · Компоненты

Каждый компонент — один файл в `site/src/components/` с тем же именем. Страницы не стилизуют компоненты заново: только классы отсюда и раскладочные утилиты (`row`, `stack`, `grid`, `gap-*`).

Формат карточки: **Назначение · Анатомия · Варианты · Состояния (таблица) · Показ/скрытие · Движение · Доступность · Тексты · Нельзя · React**.

Принудительные классы `is-hover`, `is-focus`, `is-active` существуют только для макетов, документации и тестов-скриншотов. В продукте состояние даёт браузер (`:hover`, `:focus-visible`, `:active`); JS их не ставит.

---

## 1. Button

**Назначение.** Любое действие: отправить, перейти к шагу, открыть диалог. Ссылка-переход внутри текста — это `Link`, не кнопка.

**Анатомия.** `[иконка 18?] Текст [иконка 18?]`, высота 44, поля 18, радиус 12, Manrope 600 15 px. Иконка слева — смысл действия, справа — только стрелка «дальше».

**Варианты.**

| Класс | Когда | Сколько на экране |
|---|---|---|
| `btn btn--primary` | главное действие экрана | **одна** (плюс одна в открытом диалоге) |
| `btn btn--secondary` | второстепенное действие рядом с primary, действия в карточках | сколько нужно |
| `btn btn--ghost` | третий уровень: «Отмена», «Пропустить», «Изменить» в строке | сколько нужно |
| `btn btn--danger` | выход из аккаунта, удаление | одна в зоне |
| `btn--lg` (54 px, радиус 14) | hero, главное действие формы авторизации и оплаты | — |
| `btn--sm` (34 px, радиус 8) | в строках, шапке, внутри `copy` | — |
| `btn--block` | на всю ширину: формы, карточки на телефоне | — |
| `btn--icon` (44×44) | кнопка только с иконкой (QR, меню) | — |

**Состояния.**

| Состояние | primary | secondary | ghost | danger |
|---|---|---|---|---|
| default | фон `--accent`, текст `--accent-ink` | фон `--bg-elevated`, рамка `--line-strong` | прозрачный, текст `--fg-muted` | фон `--danger-soft`, текст `--danger-fg`, рамка 25 % |
| hover | фон `--accent-hover` | фон `--bg-hover` | фон `--bg-hover`, текст `--fg` | фон danger 20 % |
| focus | кольцо 2 px `--info`, отступ 2 px | то же | то же | то же |
| active | `scale(.97)` за 120 мс | то же | то же | то же |
| disabled | `opacity .45`, курсор не реагирует, `disabled`/`aria-disabled` | то же | то же | то же |
| loading | текст прозрачный, в центре спиннер 18 px цвета текста; ширина не меняется; клики игнорируются | спиннер `--fg` | спиннер `--fg` | — |

Переходы: фон/рамка/цвет 200 мс `--ease-out`, нажатие 120 мс.

**Показ/скрытие.**
- Кнопку, которую нельзя нажать **из-за данных пользователя** (не отмечена галочка, нет изменений), показываем выключенной с подписью-причиной под ней (`t-xs subtle`): «Кнопка станет активной, когда отметите галочку».
- Кнопку, которая **не имеет смысла** в этом состоянии (нет подписки → нет «Продлить»), не рендерим.
- Во время запроса кнопка в `loading`, соседние кнопки той же формы — `disabled`.

**Доступность.** `<button type="button|submit">` для действий, `<a href>` для переходов (стиль тот же). У `btn--icon` обязателен `aria-label`. В `loading` — `aria-busy="true"`, текст для экранного диктора не меняется.

**Тексты.** Глагол + объект: «Пополнить на 500 ₽», «Добавить в Happ», «Отправить заявку». Не «ОК», не «Отправить» без объекта (кроме короткого «ОК» в поле промокода на узкой карточке). Сумма в кнопке оплаты обязательна.

**Нельзя.** Две primary рядом. Красная кнопка для отмены. Кнопка-ссылка внутри абзаца. Менять ширину кнопки при загрузке. Иконка без текста, если места хватает на текст.

**React.** `<Button variant="primary|secondary|ghost|danger" size="sm|md|lg" block loading disabled icon={<Icon/>} as="a" href>`.

## 2. Link

`link` — синяя (`--info-fg`), 600, без подчёркивания; **hover** — подчёркивание; **focus** — кольцо. Внутри обычного текста документов (`doc`) и футера ссылки цвета текста с подчёркиванием (`--line-strong`, на hover `--fg-muted`).
Внешние ссылки (App Store, Google Play, ЮKassa) открываются в той же вкладке, кроме чека и документа ЮKassa — `target="_blank" rel="noopener"`.
Ссылка «назад» в кабинете — `back` (стрелка + текст, `--fg-muted`, hover `--fg`).

## 3. Spinner

`spinner` 28 px, кольцо `--line-strong` с зелёным сегментом, оборот 0.8 с линейно. Только для **ожидания без формы**: «Подтверждаем…» на страницах из писем, «Открываем Happ…», «Готовим оплату…». Для первой загрузки данных — скелетон, для кнопки — её `loading`. Рядом всегда текст, что именно ждём. `role="status"`.

## 4. Field + Input

**Анатомия.** `field` = `field__label` (13/600, `--fg-muted`) → `input` → `field__hint` (13, `--fg-subtle`) или `field__error` (13, `--danger-fg`). Метка всегда видимая, `placeholder` — только пример значения, не замена метке. Необязательное поле помечается в метке: «Email для чека <span class="subtle">(необязательно)</span>».

**Варианты.** `input` (44 px), `input--lg` (52 px, формы входа), `input--mono` (ID, суммы, ИНН, коды), `textarea.input` (высота от 96 px, `padding:12px 14px`, растёт до 240), `input-group` (поле + кнопка в ряд: промокод).

**Состояния.**

| Состояние | Вид |
|---|---|
| default | фон `--bg-elevated`, рамка `--line-strong`, плейсхолдер `--fg-subtle` |
| hover | рамка `--line-hover` |
| focus | рамка `--info` + кольцо 3 px `rgba(59,130,246,.25)`; системный outline выключен |
| filled | как default, текст `--fg` |
| error | `is-invalid`: рамка `--danger-fg` + кольцо 3 px 18 %; под полем `field__error` вместо `field__hint`; `aria-invalid="true"`, `aria-describedby` → id ошибки |
| success | рамку не красим; подтверждение — `field__hint ok` («Скидка 10% — минус 72 ₽», «Надёжный») |
| disabled | `opacity .5`, `cursor:not-allowed`; используем только для полей, зависящих от другого поля |
| readonly | вместо поля показываем значение в `copy` или `kv` |

**Когда показывать ошибку.** После первой потери фокуса или после попытки отправки; дальше — при каждом вводе, пока поле не станет верным (ошибка исчезает сразу, без анимации). Ошибка сервера, относящаяся к полю, ставится на это поле; общая — `alert alert--bad` над кнопкой.

**Пароль.** Поле пароля с кнопкой «показать» нам не нужно на этом этапе; индикатор силы `meter` (3 сегмента) появляется под полем, как только введён первый символ: `meter--1` «Слабый» (`--danger-fg`), `meter--2` «Средний» (`--warning-fg`), `meter--3` «Надёжный» (`--accent`). Подпись — в `field__hint` того же цвета.

**Ввод чисел.** Суммы и ИНН — `inputmode="numeric"`, mono, разделители разрядов ставятся при потере фокуса (`10 000`), при фокусе — без пробелов. HiEarth ID — `inputmode="numeric"`, группы по 4 через пробел ставятся по ходу ввода; при отправке пробелы убираются.

**Доступность.** `<label for>` у каждого поля; скрытая метка — класс `sr` (поле промокода). Ошибка связана через `aria-describedby`. Автозаполнение: `autocomplete="username"`, `current-password`, `new-password`, `email`.

**Нельзя.** Красить метку в красный. Показывать ошибку, пока человек печатает первый раз. Плейсхолдер вместо метки. Ошибка тостом для поля формы.

**React.** `<Field label hint error optional id>{<Input mono size="lg" .../>}</Field>`.

## 5. Checkbox

`check` = `input[type=checkbox]` 20×20 (радиус 6, рамка 1.5 px `--line-strong`) + текст 15 px. **hover** рамка `--line-hover`; **checked** заливка `--accent`, галочка `--accent-ink`, переход 200 мс; **focus** кольцо на квадрате; кликабелен весь текст. Используется для подтверждений («Я сохранил свой HiEarth ID…»), не для настроек — для настроек `switch`.

## 6. Switch

`input.switch` (role switch) 44×26, ручка 20 px. **off** — дорожка `--line-strong`; **on** — `--accent`, ручка сдвигается на 18 px пружиной (320 мс `--ease-spring`); **focus** — кольцо; **hover** — без изменений; **disabled** — `opacity .45`.
Поведение: переключение отправляет запрос сразу (без кнопки «Сохранить»). Пока запрос идёт — переключатель уже в новом положении и `disabled`; ошибка → возврат в прежнее положение + тост `toast--bad` «Не удалось изменить автопродление». Подпись слева — `b` (что включаем) + `t-sm subtle` (последствие). `aria-label` или связанная метка обязательны.

## 7. Segmented control

`seg` — 2–4 взаимоисключающих варианта одного уровня: период трафика, документ, фильтр истории, устройство в инструкции. Внутри скрытые `input[type=radio]` + `label`.
**default** текст `--fg-muted`; **hover** текст `--fg`; **checked** фон `--bg-elevated`, рамка-кольцо `--line-strong`, текст `--fg`; **focus** кольцо `--info` на подписи; переход 200 мс. Переключение мгновенное, содержимое под ним меняется через `swap` (fade 200 мс). `role="radiogroup"` + `aria-label`; если сегмент переключает вкладки документа — `role="tablist"`. Стрелки ←/→ двигают выбор (нативно у radio).
Больше 4 вариантов — не сегмент, а список или select.

## 8. Amount picker

`amounts` — быстрые суммы пополнения (300 / 500 / 1 000 / 2 000 ₽, список из API или константы страницы кошелька) + поле «Своя сумма».
**default** рамка `--line-strong`; **hover** рамка `--line-hover`; **checked** рамка `--accent`, фон `--accent-soft`, текст `--accent-fg`; **focus** кольцо.
Ввод в «Своя сумма» снимает выбор с быстрых сумм; клик по быстрой сумме очищает поле. Кнопка ниже всегда показывает итог: «Пополнить на 500 ₽». Пусто и ничего не выбрано → кнопка `disabled` с текстом «Пополнить».

## 9. Select

`sel` — нативный `<select>` 32 px (роль сотрудника в B2B). **hover** рамка `--line-hover`, **focus** кольцо. Смена значения отправляет запрос сразу: на время запроса `disabled`, ошибка → откат + тост. Свой выпадающий список не рисуем.

## 10. Card

`card` — фон `--bg-raised`, рамка `--line`, радиус 20, поля 24. Шапка карточки `card__head`: слева `card__title` (14/700, `--fg-muted`), справа бейдж или ссылка («История»).

| Вариант | Когда |
|---|---|
| `card` | любой блок контента |
| `card--flat` | группа без фона (на лендинге внутри секций) |
| `card--elevated` | карточка внутри карточки или поверх фирменного фона (макет «экрана» на главной) |
| `card--link` | вся карточка — переход. **hover**: подъём на 2 px, рамка `--line-strong`, фон `--bg-elevated` (200 мс); **focus** кольцо; **active** без подъёма |
| `card--glow` | главная карточка экрана с выбранным/рабочим состоянием: подключение на обзоре. Рамка `--accent-line`, `--shadow-lift`, мягкий зелёный градиент сверху. **Одна на экран** |

Карточка не кликабельна целиком, если внутри есть свои кнопки. Скелетон карточки — та же рамка и поля, внутри `skel`-полосы (см. §16).

## 11. Badge

`badge` 24 px, капсула, точка 6 px цвета текста + текст 12/700. Варианты: `--ok` (Активна, Оплачено, Зачислено, Подтверждена, Работает), `--warn` (Ожидание, истекла, Биллинг), `--bad` (Отклонён, Не прошла, Закрыт), `--info` (Возврат, Админ), без модификатора — нейтральный (Отменён, На паузе, Готов, Сотрудник), `--plain` — без точки (служебные метки «необязательно», «Нет активной подписки»).
Бейдж не кликабелен, без hover. Появление — без анимации; смена статуса на живой странице (ожидание → оплачено) — `swap`.

## 12. Kbd

`kbd` — номер шага в мобильном списке шагов и сочетания клавиш. Не кнопка.

## 13. Alert

`alert` — сообщение, **встроенное в страницу**: иконка 18 + текст 14/1.5, первая фраза жирная (что случилось), дальше — что делать.

| Вариант | Когда | Пример |
|---|---|---|
| `alert--info` | пояснение к действию | «Оплата с кошелька. Если денег не хватает…» |
| `alert--ok` | подтверждённое условие | «Вас пригласил друг — после первой оплаты…» |
| `alert--warn` | нужно действие, но ничего не сломано | «На кошельке 430 ₽, к оплате 648 ₽…» |
| `alert--bad` | ошибка загрузки/операции, которая блокирует экран или форму | «Аккаунт не найден. Проверьте ID…» |

Показ: появляется на месте (без сдвига кнопок под ним в момент нажатия — место под alert ошибки формы резервировать не нужно, он появляется над кнопкой с `rise` 320 мс). Скрывается, когда причина устранена (исправили поле, успешно повторили) — без анимации. Кнопки внутри alert — `btn--sm` secondary/ghost или `link`. Закрывающего крестика у alert нет. `role="alert"` для `--bad`, `role="status"` для остальных.

## 14. Toast

`toast` — короткий отклик **на действие, у которого нет места на странице**: «Скопировано» (если кнопка не меняется сама), «Изменения сохранены», «Промокод активирован», «Заявка на возврат отправлена», ошибки переключателей и select.

**Анатомия.** Иконка в плашке 28 px (`toast__ic`: успех — зелёная, `toast--bad` — красная) + текст 14/600 + для ошибок крестик `toast__x`.
**Где.** Контейнер `toasts`: справа снизу (24 px от краёв); на телефоне снизу по центру во всю ширину с полями 16 и учётом safe-area.
**Жизнь.** Успех — 4 с, затем выход. Ошибка — пока не закроют (крестик) или 8 с. Наведение мыши на тост останавливает таймер. Одновременно не больше 3, новый — снизу, старые поднимаются. Одинаковый текст не дублируется: повтор перезапускает таймер.
**Движение.** Вход `he-toast` 320 мс (снизу 12 px + scale .98 → 1); выход `is-leaving` → `he-toast-out` 160 мс, потом удаление из DOM.
**Доступность.** Контейнер `role="status" aria-live="polite"`, ошибки — `role="alert"`. Тост не забирает фокус. Действий-кнопок внутри тоста нет (кроме крестика).
**Нельзя.** Тост вместо ошибки поля. Тост для того, что уже видно на странице. Тосты при загрузке страницы.

## 15. Dialog

`overlay` (подложка `--overlay` + blur 6, `position:fixed`, `z-index:40`) → `dialog` (max 440, поля 28, радиус 28, `--bg-raised`, `--shadow-pop`). Внутри: заголовок `t-h3`, текст `muted`, при нужде поля, ряд кнопок справа (`row gap-2`, на телефоне — `btn--block` столбиком, главная снизу).

**Когда.** Только (1) подтверждение необратимого или выводящего из аккаунта действия («Точно выйти?», «Удалить сотрудника?», «Удалить почту?»), (2) короткая форма по месту («Запросить возврат»), (3) крупный показ одного объекта (QR-код). `window.confirm/alert/prompt` запрещены.
**Кнопки.** Слева отмена (`ghost`: «Остаться», «Отмена», «Не сейчас»), справа действие (`primary`, либо `danger`, если действие выводит/удаляет). В диалоге одна главная кнопка.
**Открытие.** Подложка `he-fade` 200 мс, диалог `he-dialog` 320 мс (scale .96 + 6 px → 1). Фокус переходит на первую интерактивную строку (поле или кнопку отмены для опасных действий). Прокрутка страницы под диалогом блокируется.
**Закрытие.** `Esc`, клик по подложке (кроме диалога с заполненной формой — там только кнопками), кнопка отмены. Выход: `is-leaving` → подложка `he-fade-out` 160 мс, диалог `he-dialog-out` 160 мс, затем удаление. Фокус возвращается на кнопку, открывшую диалог.
**Во время запроса.** Главная кнопка `loading`, отмена `disabled`, `Esc` и подложка не закрывают. Ошибка — `field__error` у поля или `alert--bad` над кнопками; диалог остаётся открытым. Успех — диалог закрывается + тост.
**Доступность.** `role="dialog" aria-modal="true" aria-labelledby` → заголовок; фокус зациклен внутри.

## 16. Skeleton

`skel` — серая плашка `--bg-elevated` с пульсом прозрачности (1.6 с). Повторяет форму будущего контента: строка текста — высота 12–16, ширина 40–80 %; цифра баланса — 120×32; карточка тарифа — карточка с 4 полосами. Показ: первая загрузка данных, если ответ дольше 300 мс (до этого — пусто, чтобы не мигать). Смена скелетона на контент — `swap`. Повторные загрузки (смена периода трафика, фильтр) скелетон не показывают: старые данные остаются, приглушаются до `opacity .5`, после ответа меняются.
`aria-busy="true"` на контейнере, скелетоны `aria-hidden`.

## 17. Empty state

`empty` — по центру: ёжик (`hh--search` для «пусто», `hh--idle` для подсказки) 132 px → `empty__t` (18/700) → `empty__d` (15, `--fg-muted`, max 360) → одна кнопка (secondary или primary, если это главное действие экрана). Тексты говорят, **что здесь появится и как это вызвать**: «Платежей пока нет. Здесь появятся все оплаты и чеки после первой покупки.»
Маленькая версия внутри карточки — без ёжика, только `empty__t` + `empty__d` + `btn--sm`.

## 18. CopyField

`copy` — значение mono 13 (`copy__v`, обрезка многоточием, `user-select:all`) + кнопка `btn--sm` «Копировать» справа. Рамка `--line-strong`, фон `--bg`; **hover** рамка `--line-hover`.
**Действие.** Клик по кнопке (или по значению — выделяет его целиком) → `navigator.clipboard.writeText` → контейнер получает `is-copied` на **2 с**: рамка `--accent-line`, кнопка зелёная мягкая с текстом «✓ Скопировано», затем возврат. Тост не нужен. Ошибка буфера (нет прав, http) → значение выделяется, кнопка показывает «Выделено — нажмите Ctrl+C» (на телефоне «Выделено — скопируйте») на 3 с.
**Длинные значения.** Ссылка подписки обрезается; рядом `btn--ghost btn--sm` «Показать ссылку целиком» → значение переносится по словам (`white-space:normal; word-break:break-all`), кнопка меняется на «Скрыть».
**Секреты.** Ссылка подписки и QR — это доступ к подписке: рядом подпись «Не показывайте посторонним».

## 34. Фирменные элементы

Четыре элемента делают сайт узнаваемым. Их нельзя перерисовывать, менять цвета или добавлять пятый без правки этой спецификации.

### 34.1 ConnectOrb — статус подключения

`orb` 200 px (`orb--sm` 120; на телефоне 160 через размер): внешнее кольцо-пульс, мягкий зелёный ореол, ядро `orb__core` с иконкой щита-галочки 52 px и подписью `orb__label`.

| Состояние | Когда | Вид | Подпись |
|---|---|---|---|
| on | подписка активна | кольцо пульсирует (2.6 с, бесконечно), ореол, зелёное ядро | «Готово» (кабинет), «Подключено» (макет на главной) |
| off (`orb--off`) | нет подписки, истекла, загрузка не удалась | серое кольцо без пульса, без ореола, ядро `--bg-elevated`, иконка `--fg-subtle` | «Нет подписки», «На паузе» |
| hover | курсор над орбом | ядро `scale(1.02)` 200 мс | — |

Это **индикатор, а не кнопка**: клик ничего не делает, курсор обычный. Действие рядом — «Добавить в Happ». Подписка — состояние аккаунта; включено ли подключение в Happ, сайт не знает, поэтому слово «Подключено» в кабинете не пишем. `role="img" aria-label="Подписка активна"` / «Подписки нет». Reduced motion — без пульса.

### 34.2 Flap — перекидные цифры

`flap` — каждая цифра в отдельной плашке `b` (mono 600, верх/низ разного тона, линия сгиба), разделители и единицы — `i` (мельче, `--fg-muted`). Размер задаётся `font-size` контейнера (30–44 px в карточках, 34 на телефоне).
- **Где:** баланс кошелька, «Осталось N дн», сумма к оплате/пополнению, оплаченная сумма в результате, сумма счёта, оценка B2B, «404», бонус 100 ₽ на странице приглашения, таймер-время в макете на главной.
- **Где нельзя:** цены в каталоге тарифов (там обычный `plan__price`), суммы в строках истории, любые числа меньше 14 px.
- **Движение:** при появлении каждая цифра переворачивается сверху (620 мс, задержка `--i` × 70 мс + `--d`). При изменении значения перекидываются **только изменившиеся** разряды (React: ключ `${индекс}-${цифра}`). Тон: `flap--accent` — деньги пришли/срок активен; `flap--warn` — не хватает, мало дней; без модификатора — нейтрально.
- **Доступность:** контейнер `role="img"`/`aria-label="430 рублей"`, отдельные плашки `aria-hidden`.
- **React:** `<Flap value={430} suffix="₽" tone="accent|warn" size={32} delayMs label/>`.

### 34.4 Hedgehog — ёжик

Одна SVG-разметка (`react/Hedgehog.jsx`), настроение — классом:

| Настроение | Класс | Анимация | Где |
|---|---|---|---|
| спокоен | `hh--idle` | дышит (3.2 с), моргает (4.6 с) | подсказки, пустые блоки без проблемы |
| рад | `hh--happy` | глаза-дуги, улыбка, 2 подскока шипами, мерцают искры | оплата прошла, ID выдан, почта подтверждена, бонус за друга |
| спит | `hh--sleep` | глаза закрыты, медленное дыхание (4.8 с), всплывают «z» | подписка истекла, напоминания отключены |
| волнуется | `hh--worried` | бровь, капля пота покачивается | оплата не прошла, код не активирован, ошибка загрузки страницы |
| ищет | `hh--search` | лупа покачивается | 404, пустые списки, «проверяем…» |

Правила: **не больше одного ёжика на экран**; всегда `aria-hidden="true"` — смысл несёт текст рядом; размер 120–150 px (в `empty` 132); не используется в кнопках, тостах и шапке; не говорит репликами в облачках. Reduced motion — статичная поза настроения.
