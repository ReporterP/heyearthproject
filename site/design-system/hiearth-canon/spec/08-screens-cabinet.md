## 8.1 Обзор `/dashboard`

**Паспорт.** `DashboardPage.jsx` · артборды «Кабинет: активна», «нет подписки», «закончилась», «телефон».
**Данные.** `useAccount(['profile','subscription','traffic','subLink','wallet'])` + `GET /api/v1/referral` (статистика друга) + `GET /api/v1/user/mtproto` (Telegram) + `GET /api/v1/wallet/quote` (сколько не хватает до продления). Состояние экрана выбирается по `subscription`: **active**, **none**, **expired**. Пока данные грузятся — скелетоны карточек в той же сетке.

**Раскладка (как на артборде «активна»).** Десктоп: `page-head` → сетка 12 рядами: Подключение `card--glow` 7 + Подписка 5 → Кошелёк 4 + Трафик 5 + Друг 3 → Как начать 7 + Промокод 5 (нет друга — Трафик растягивается до 8; «Как начать» скрыта — Промокод на 12). «нет подписки»: главная карточка 8 + Кошелёк 4 → Подключение-заглушка 8 + Промокод 4. «закончилась»: главная 8 + Кошелёк 4 → «Подключение на паузе» 12 → Друг 5 + Промокод 7 (промокод есть всегда, 03 §11). Планшет (≤1024): одна колонка, порядок как на телефоне. Телефон: Подключение → Подписка → Кошелёк → Трафик → Друг → Как начать → Промокод → навигация `nav.card` (Оплата и подписка, Настройки, Помощь).

## 8.3 Открытие приложения `/connect?sub=<token>`

**Паспорт.** `ConnectPage.jsx` · артборд «Подключение» · доступна без входа (ссылка может прийти на другое устройство) · узкая шапка: `back` «Назад в кабинет» (вошедшему) · логотип · `tag--chip`.
**Данные.** `GET /api/v1/user/happ-link/<token>` → `happ://…`. Ответ 400/404 → bad-link; сеть или 5xx → открываем `happ://add/<адрес подписки на этом сайте>` (Happ принимает и его). На Android вызывается `intent://…;package=com.happproxy;S.browser_fallback_url=<Google Play>` — без Happ телефон сам откроет магазин.

| Состояние | Что видно | Переход |
|---|---|---|
| preparing | `spinner` + H1 «Готовим ссылку…» | ответ API |
| opening | H1 «Открываем Happ…» + «Если приложение не открылось само, выберите устройство ниже. После установки вернитесь и нажмите кнопку ещё раз.»; страница вызывает `location.href = happ://…` | через 2.5 с, если вкладка всё ещё видима (`visibilitychange` не наступил) → not-installed |
| not-installed | `alert--warn` «**Похоже, приложение не установлено.** Скачайте его — или добавьте подписку вручную ниже.» → 3 строки `dl` (iPhone и iPad · App Store, Android · Google Play, Компьютер · Windows, macOS, Linux) → `btn--secondary` «Попробовать снова» | «Попробовать снова» — повторный вызов `happ://` |
| manual (всегда ниже) | `h2.t-h3` «Вручную» + «Скопируйте ссылку подписки и вставьте в приложение: Happ — «+» → «Вставить из буфера».» + `copy` + `btn--ghost btn--sm` «Показать QR-код» | — |
| bad-link | `mini` с `hh--worried`: «Ссылка некорректна» + «В ссылке нет ключа подписки. Откройте «Подключение» в кабинете и нажмите «Добавить в Happ».» + `btn--secondary` «К подключению» → `/connect` | нет `sub` или API 404 |

**Диалог QR.** Заголовок «Отсканируйте с телефона», `qr` 184 px, текст «Камерой телефона или из Happ: «+» → «Сканировать QR». Не показывайте код посторонним — это доступ к вашей подписке.», одна кнопка `btn--secondary btn--block` «Закрыть». Тот же диалог открывается с обзора и `/connect`.
**Главная кнопка** на этой странице отсутствует намеренно: главное действие уже выполнено автоматически; «Скачать» — secondary.
