# 10 · Экраны для бизнеса

Все маршруты обёрнуты в `B2BOnly`: пока `site-info.b2b_enabled` выключен, они отвечают как 404 (6.4), а ссылки «Для бизнеса» нигде не показываются. Цены и состав — из API (`/api/v1/site-info` или будущий тарифный эндпоинт B2B); на макетах базовые значения.

## 10.2 Подключение компании `/business/signup`

**Паспорт.** `BusinessSignupPage.jsx` · артборд «Подключение бизнеса» · все · шаги `steps`: Параметры → Контакт → Готово · `back` «Для бизнеса».

| Шаг | Элементы | Действие / состояния |
|---|---|---|
| 1 Параметры | «Сколько сотрудников» (`input--mono`, по умолчанию 10) · «Серверы» `seg`: Наши / Свои (+ «Сколько своих серверов», если «Свои») · `btn--primary` «Дальше» | значения сразу пересчитывают оценку справа |
| 2 Контакт | «Название компании» (placeholder «ООО «Компания»») · «Email» · `btn--ghost` «Назад» / `btn--primary` «Получить доступ» | пустой email → `is-invalid` «Укажите email»; отправка → `POST /api/public/create-tenant` → `loading` → шаг 3; ошибка — `alert--bad` над кнопками |
| Справа на шагах 1–2 | `card` «Предварительная оценка»: `flap` «3 500 ₽/мес» + расшифровка («10 сотрудников × 250 ₽», «Наши серверы — 1 000 ₽») + «Оплата — через пополнение кошелька в панели. Сейчас ничего не спишется.» | `flap` перекидывает изменённые цифры при каждом изменении параметров |
| 3 Готово | ёжик `hh--happy`, `t-h2` «Аккаунт компании создан», «Зарегистрируйтесь на сайте, затем откройте эту ссылку — мы привяжем ваш аккаунт к компании.», `copy` со ссылкой `/claim/<код>`, `btn--primary` «Зарегистрироваться» → `/register?redirect=/claim/<код>` · `btn--ghost` «Войти в аккаунт» → `/login?redirect=/claim/<код>` | вошедшему — одна кнопка «Привязать мой аккаунт» → `/claim/<код>`. Ответ без `claim_url` (старый сервер): «Письмо с инструкциями отправлено на <email>. Войдите в свой аккаунт — компания уже привязана к нему.» + те же кнопки без `redirect` |

H1 «Подключение бизнес-аккаунта» + «Без предоплаты на сайте. Оплата — после входа в панель управления.» над шагами 1–2. Шаг 3 заменяет форму `swap`, шаги показывают 1 ✓ 2 ✓ 3 активен.

## 10.4 Кабинет компании `/business/dashboard`
