# 04 · Движение

Движение объясняет, что произошло: что появилось, что изменилось, где был нажат элемент. Украшательского движения нет, кроме четырёх фирменных элементов, которым позволено «жить».

## 1. Токены

| Токен | Значение | Для чего |
|---|---|---|
| `--dur-1` | 120 мс | нажатие, мелкие цвета (крестик тоста, пункты оглавления) |
| `--dur-2` | 200 мс | наведение, смена фона/рамки, fade подложки, `swap` |
| `--dur-3` | 320 мс | появление диалога, тоста, раскрытие `collapse`, переключатель, меню |
| `--dur-4` | 600 мс | вход контента страницы (`rise`), рост столбиков |
| `--ease-out` | `cubic-bezier(.23,1,.32,1)` | всё появляющееся и почти всё остальное |
| `--ease-in-out` | `cubic-bezier(.65,0,.35,1)` | бесконечные циклы (дыхание, покачивание, пульс скелетона) |
| `--ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | **только** ручка переключателя, подскок ёжика и `pop` |

Исчезновение всегда быстрее появления: 160 мс. Анимируются только `opacity`, `transform`, `filter` (в `rise`), `grid-template-rows` (в `collapse`) и цвета. Не анимируем `width/height/top/left`, тени, размер шрифта.

## 3. Хореография входа страницы

Одна оркестрованная сцена на страницу при монтировании; при прокрутке ничего не «выезжает».

| Тип страницы | Порядок (`--d`) |
|---|---|
| Главная, B2B, приглашение | H1 0 → лид 120 → кнопки 200 → подпись 280 → «экран»-карточка справа 200; flap внутри стартует с `--d` 500 |
| Кабинет | H1 и лид без анимации (страница рабочая); главные карточки `rise` 0 / 80 / 160 по колонкам; цифры `flap` внутри — сразу с переворотом |
| Авторизация | H1 0 → лид 120 → кнопка 200; правая половина — фирменный элемент со своей анимацией |
| Оплата | шаги и H1 без анимации; карточка расчёта `rise` 0; сумма к оплате — `flap` |
| Короткие (`mini`, `res`, 404) | вся карточка `pop` (spring 320) ; ёжик в своём настроении; flap — с `--d` 200 |

Правила: шаг между элементами 60–120 мс; всего не дольше 900 мс до последнего элемента; вход не блокирует клики (кнопки кликабельны с первого кадра).

## 4. Отклик на изменения данных

| Изменение | Отклик |
|---|---|
| Баланс/сумма/дни изменились | перекидываются только изменённые цифры `flap` |
| Статус платежа сменился | бейдж и текст — `swap`; новый пункт таймлайна — `rise` |
| Промокод применён | строка «Скидка…» появляется `rise`; итог перекидывается; бейдж «Применён» — `pop` |
| Пункт чеклиста выполнен | кружок заливается зелёным (200 мс), галочка `pop`, текст зачёркивается |
| Список отфильтрован | старые строки исчезают сразу, новые — `swap` контейнера |
| Строка удалена (сотрудник) | высота схлопывается через `collapse` 320 мс после закрытия диалога |

## 5. Сниженное движение

`prefers-reduced-motion: reduce` — в `hiearth.css` все анимации и переходы укорачиваются до 1 мс и одного повтора: пульс орба, покачивание бирки, дыхание ёжика останавливаются в финальной позе; `flap` показывает итоговые цифры; плавная прокрутка якорей выключается. Смысл не теряется: все состояния различимы без движения (текст, цвет, форма).

## 6. Нельзя

- Анимация при прокрутке (parallax, появление секций по скроллу).
- Бесконечные анимации у чего-либо, кроме: орб on, `tag--idle`, ёжик, спиннер, скелетон, `is-now` в таймлайне.
- Движение на действия с клавиатуры (переход по Tab не анимируется).
- Задержки, из-за которых кнопка видна, но не реагирует.
- Анимация длиннее 600 мс у интерфейсных элементов (кроме фирменных).
