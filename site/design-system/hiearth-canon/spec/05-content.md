# 05 · Тексты

## 1. Голос

Спокойный знающий друг, который объясняет коротко и честно. На «вы» (с маленькой буквы). Без восклицательных знаков, кроме «Готово!» на коде компании. Без канцелярита («осуществить», «данный»), без маркетинговых превосходных степеней («лучший», «молниеносный»), без страха («вас взломают»).

Каждое сообщение отвечает на один из вопросов: что это, что случилось, что делать дальше.

## 3. Чего не выдумываем

Отзывы, рейтинги, число пользователей, аптайм в процентах, скорость, «серверов в N странах», «ежедневно проверяем…», логотипы клиентов B2B, сроки, которых нет в документах. Факты, которые можно писать: первая неделя бесплатно (если тариф есть в API), безлимитный трафик (если так в тарифе), карта не привязывается, данные карты вводятся только у ЮKassa, ID нельзя восстановить, автопродление только при достаточном балансе, максимум 100 000 ₽ за одно пополнение, заявка на возврат рассматривается в течение 5 рабочих дней, бонус за друга — после первой оплаты деньгами, код действует 7 дней после регистрации и до первой оплаты, приложение Happ бесплатное и есть для iPhone, Android, Windows и macOS.

## 4. Форматы

| Что | Формат | Пример |
|---|---|---|
| Деньги | разряды пробелом с 10 000 (в `flap` — всегда), `₽` через неразрывный пробел, без копеек, если их нет | `720 ₽`, `10 000 ₽`, `1 000 ₽` |
| Поступление / списание в истории | `+1 000 ₽` (зелёным), `−720 ₽` (типографский минус U+2212) | |
| Скидка | `−72 ₽`, «Скидка 10% — минус 72 ₽» | |
| Дата | «14 февраля», с годом только если не текущий: «14 февраля 2027» | |
| Дата и время | «14 ноября, 21:47» | |
| Относительное | «2 дня назад» только для «подключена» в B2B | |
| Осталось дней | «Осталось 90 дней»; в flap — `90 дн` | |
| HiEarth ID | как выдан, mono: `3f2b8c1e-7a4d-4e9b-8c21-5d6e7f8a9b0c`; сокращённо `3f2b…9b0c`, на телефоне `…9b0c` (02 §34.3) | |
| Трафик | `38,4 ГБ` (запятая, один знак) | |
| ИНН, коды, номера счетов | mono, как есть: `7707083893`, `7QX4-KP2M`, `№ 1042` | |
| Проценты | `20%` без пробела (как в макетах) | «Выгоднее на 20%» |
| Время ответа поддержки | «в течение дня» (как сейчас на странице помощи) | |

Склонение чисел — функцией `plural(n, ['день','дня','дней'])`, не «дн.» в тексте.

## 5. Кнопки и ссылки

Глагол в повелительном или инфинитив по смыслу + объект: «Получить HiEarth ID», «Добавить в Happ», «Пополнить на 500 ₽», «Скачать файл с ID», «Запросить возврат». Отмена — «Отмена», «Остаться», «Не сейчас», «Не надо». Переход назад — «Назад в кабинет», «В кабинет», «История платежей». В процессе — с многоточием: «Сохраняем…», «Готовим оплату…», «Считаем…», «Подождите…».

## 7. Каталог ошибок

Формат: **Что случилось.** Что делать. Сервер может прислать код ошибки — сайт сопоставляет его с этой таблицей; неизвестный код → общий текст.

| Вход: нет такого аккаунта | **Аккаунт не найден.** Проверьте ID — его легко перепутать с похожими символами. |
| Вход: неверный пароль | **Неверный пароль.** Если пароль не задавали — оставьте поле пустым. |
| Вход: слишком много попыток (429) | **Слишком много попыток.** Подождите минуту и попробуйте снова. |
