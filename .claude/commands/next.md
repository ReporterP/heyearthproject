description: Показать что делать дальше (ready-задачи из Beads, активные артефакты, статус)
---

Покажи пользователю текущее состояние работы в проекте. Это быстрый обзор без действий.

## Секция 1: Активные эпики и планы

Сканируй `docs/plan/*.md` (игнорируй `_template.md`). Для каждого:
- Название
- Beads ID
- Статус (из frontmatter)
- Процент выполнения (считай `- [x]` vs `- [ ]` в соответствующем `docs/tasklist/`)

## Секция 2: Beads ready front

Если Beads доступен:
```bash
bd ready
```
Покажи список задач без блокеров — эти можно брать в работу прямо сейчас.

Если Beads недоступен:
- Найди в `docs/tasklist/*.md` первую незакрытую `- [ ]` задачу в каждом файле со статусом `in_progress`

## Секция 3: In-progress задачи

Если Beads доступен:
```bash
bd list --status in_progress
```

Это задачи, уже взятые в работу (через `bd update --claim`). Возможно остались с прошлой сессии.

## Секция 4: Side quests

Если Beads доступен — покажи задачи с типом `bug` или связью `discovered-from`, ещё не закрытые.

## Секция 5: Рекомендация

На основе состояния предложи одно из:
- `/execute <id>` — продолжить конкретную задачу
- `/feature "..."` — начать новую фичу (если ready-front пустой)
- `/finish <slug>` — финализировать эпик (если все подзадачи закрыты)
- `/fix "..."` — исправить баг (если обнаружен непредвиденный)

Держи ответ коротким — это быстрый статус, не полный отчёт.
