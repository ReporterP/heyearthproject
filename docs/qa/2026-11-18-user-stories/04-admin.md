## Находки
### S04-01 [P1] Бесконечный цикл запросов и тостов на /admins (и /tenants) при ошибке загрузки
- Где: local http://qa04.localhost:5173/admins под `qa-support` (нет `admins.read`)
- Шаги: войти как qa-support, открыть /admins (и /tenants).
- Ожидалось: один 403 и понятное «нет доступа».
- Получилось: страница шлёт 403-запросы к `admin-users`/`admin-roles`/`admin-permissions` непрерывно (~90 запросов/с: 271 за 3 с на /admins; 88 за ~1.3 с на /tenants), сыплет тосты «Нет прав на это действие». После ухода со страницы затухает за несколько секунд.
- Доказательство: счётчик в хуке fetch: «271 in 3s on /admins»; через 4 с после ухода — 0.
- Причина: `components/Toast.jsx:24` — объект `toast` пересоздаётся на каждый рендер провайдера; `pages/AdminsPage.jsx:179-183` — `load` в `useCallback(..., [toast])` + `useEffect(() => load(), [load])`: ошибка → тост → ререндер → новый `toast` → новый `load` → запрос. Тот же шаблон в TenantsPage (`toast.error(e.message)` в загрузке, :64). Любая ошибка API (500, обрыв сети, 429) на этих страницах даст такой же шторм, не только 403 — и нагрузит API/лимитер.
- Артефакт локального окружения? no

### S04-02 [P2] Страницы без нужного права не отказывают, а показывают пустые данные
- Где: local qa-support: /plans, /promocodes, /servers, /direct-routes, /admins, /tenants, /payments, /alerts, /news, /mtproto
- Получилось: роутер не проверяет права (PAGE_PERMS используется только для меню и палитры, `auth/access.js`), страницы грузятся и получают 403. Часть показывает правдивую ошибку (/telegram-bot «Не удалось загрузить настройки: Нет прав…»), но многие — выдумку: /plans «Нет тарифных планов. Создайте первый план», /admins «Администраторов нет», /direct-routes «0 сервисов, Нет сервисов», /audit-log «Журнал пуст», /tenants «Тенанты не найдены». В шторке пользователя вкладка «Подписки»: «Подписки не найдены. Добавьте первую через кнопку выше» при 403. Кнопки записи («+ Добавить сервис», «Создать план») остаются, нажатие даёт 403-тост.
- Ожидалось: «нет доступа» вместо пустого списка (или редирект на /dashboard).
- Доказательство: тексты страниц выше; 403 в сети на каждой.
- Артефакт? no
