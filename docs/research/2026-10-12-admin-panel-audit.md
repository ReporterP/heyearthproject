# Аудит админки для самообслуживания владельца (research, 2026-10-12)

> Статический разбор `admin_web` + `internal/admin` + `cmd/api/*admin*` (code-explorer), ветка `vpn/stabilization`.
> Цель: владелец-не-разработчик сам настраивает всё из подпроектов 1–2. Строки файлов — на момент аудита.

## Главное
- **Опасно сейчас:** кнопки, ломающие туннель (`fetch_tunnel_creds`, `sync_tunnel`, `sync_metrics`);
  секреты в браузере (`GET /servers/{id}` — SSH-пароль/ключи туннеля; `GET /settings` — секрет ЮKassa,
  SMTP-пароль, obfs/stats Hysteria, приватный ключ AWG); **возврат денег без проверки права**
  (`routes.go:122-129` → `admin_payment_actions.go`, только AuthMiddleware) через `prompt()`.
- **Неправда в UI:** «Online» у всех серверов (список не отдаёт `lifecycle_state`), «Статус» = доступность
  node-agent, фильтры lifecycle/страны игнорируются, колонка «План» у пользователей всегда «—»
  (`u.plan` vs `current_plan`), карточка Бамбука недостижима (рисуется при `!is_exit_node`, а Hub не в `servers`),
  «Хост главного сервера» в Settings на деле SNI сертификата Бамбука, настоящий `main_server_host`/`site_url` не видны.
- **Сломано:** создание админов/ролей (`role_ids`/`key` vs `role_keys`/`role_key`), создание пользователя
  (`username/password` vs `user_id`), правка SSH-ключа без замены, сохранение MTProto затирает
  `mtproto_port/host`, фильтры подписок/платежей/аудита, хоткеи j/k/Enter глотают ввод (`useHotkey.js:17`),
  403 разлогинивает (`client.js:31-34`), права заморожены в JWT, UI проверяет `servers.write` а бэкенд
  `server_ops.execute`.
- **Auto-Tuner:** переключатель без предупреждения (тюнер тихо меняет SNI/obfs → профили ломаются,
  `config_version` не растёт); «Запустить сейчас» ничего не делает, если тюнер был выключен при старте API.
- **Провижининг:** API перезапускает сам себя (`servers_handlers.go:1791`) → шаг MTProxy не выполняется,
  прогресс теряется, модалка `ProvisionProgressDialog` зависает (не закрывается до `finished`).
- **Тема:** `style.css:3-24` перебивает токены (Inter, slate, cyan), акцент по умолчанию синий,
  ThemePicker предлагает светлые темы; 201 нарушение в 21 файле; 4 способа подтверждений, 2 системы модалок,
  9 сырых `fetch`, легаси-модалки не полноэкранные на мобиле.
- **Нет единой картины:** бэкапы, guard, режим PROXY, версии, сервисы — только из CLI; алерты сырыми ключами.

## Настройки (`app_settings`) — что владельцу нужно видеть/менять
| Ключ | Сейчас | Решение |
|---|---|---|
| `main_server_host` | нигде | Домены/Входы (Ф3–Ф4) |
| `hub_main_server_host` | Settings с ложной подписью | Домены (сертификат Бамбука), только просмотр до Ф4 |
| `reality_sni_domain`, `reality_fingerprint`, `dns_servers`, `mux_concurrency`, `balancer_strategy` | Auto-Tuner (чтение) / нигде | «Протоколы и маскировка», изменение — за предупреждением |
| `reality_transport`, `reality_flow` | чтение | не открывать |
| `quota_cutoff_enabled` | нигде | Настройки → Подписки, с показом «отключит N» |
| `ghost_auto_cleanup`/`repair` | нигде | показать в «Нодах» |
| `mtproto_*` | MTProto (порт затирается) | починить, порт только чтение |
| `hysteria2_*` статус | нигде | карточка Бамбука |
| секреты (`hysteria2_obfs_password`, `hysteria2_stats_secret`, `hub_tunnel_password`, `awg_server_private_key`) | **уходят в браузер** | никогда не показывать; obfs — «ротировать» с предупреждением |
| `yookassa_secret_key`, `smtp_password` | открытым текстом в DOM | только на запись + «Проверить» |
| `site_url` | нигде | Домены |
| `Profile-Update-Interval` | захардкожен 4 | настройка (Ф3 автоподмена) |
| мёртвые (`hub_vless_port`, `app_build_*`, `b2b_price_*`, `api_endpoints`, `mtproto_host`, `server_archive_retention_days`, `payment_provider`, `price_*`) | карточки Settings | убрать |
Общий `POST /settings` пишет любой ключ без проверки — перевести на белый список с валидацией.

## Операции из CLI → админка
Показывать (только чтение): сервисы Hub и NRestarts, версии (xray, hysteria стоит/закреплена, сборка API;
на нодах), бэкапы (последний, копия вне Hub, ошибка, следующий запуск), фаза egress guard, режим PROXY
(+ баннер «не деплоить сборки без зеркала»), сертификаты, диск/БД, логи API.
Действия: «Бэкап сейчас» (oneshot). Остаётся в CLI: restore/drill, `--setup-ops`, переключение PROXY,
`--main/--update-main/--site/--admin-web/--setup-*`.

## Переиспользовать
`components/ui/*` (Button, Input, Card, Dialog, **Drawer**, Badge, Table, Skeleton, EmptyState, PageHeader),
`useUrlState`; образец страницы настроек — `AlertsPage` (секреты только на запись, блокировка формы при ошибке,
встроенные подтверждения, баннеры). Нет в `ui/`: Wizard/Stepper, Tabs, Switch, CopyButton, ConfirmDanger —
первые кандидаты. Бэкенд: `alertManager.state` (активные инциденты) → почти бесплатный `GET /admin/health`;
`biz.GetHysteria2Status` готов.

## Предложенная структура
ОБЗОР: **Состояние** (новая первая страница: светофор по фактам + «что значит/что делать»), Дашборд, Трафик ·
КЛИЕНТЫ: Пользователи, Подписки, Промокоды · ДЕНЬГИ: Тарифы (понятные имена протоколов, привязка нод),
Платежи (возврат через диалог), Письма/повторы · СЕТЬ: **Ноды** (по ролям, правдивые состояния, мастер),
карточка ноды (Обзор/Тарифы и вес/Задачи/Журналы/Опасная зона), **Входы**, **Домены**,
**Протоколы и маскировка** (+ Бамбук, Пальма), подмена доменов, РФ-сервисы, Telegram-прокси ·
СИСТЕМА: Алерты (человеческие названия), **Обслуживание**, Настройки (блоки: Платежи, Почта, Юр., Подписки),
Администраторы, Журнал аудита, SSH-ключи, Релизы · B2B (свёрнутая группа).

## Проверить на проде
Строка `servers` с `is_exit_node=false`; `admin_users` с `tenant_id`; нестандартный `mtproto_port`.
