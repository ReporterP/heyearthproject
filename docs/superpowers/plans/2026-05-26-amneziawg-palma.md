# 🌴 Пальма AmneziaWG 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship «🌴 Пальма» — AmneziaWG 2.0 — as priority-0 subscription profile with per-plan admin toggle, plus quick wins R4 (XHTTP response chunking) and R5 (mobile-operator direct-routes). Together these defeat Tele2 cell-DPI that still catches Дуб/Бамбук after R1+R2+R3.

**Architecture:** AmneziaWG runs as `amneziawg-go` userspace binary on Hub UDP :51820, separate from existing Xray/Hysteria2. Per-user keypair + per-user randomized CPS junk-packet params (Jc/Jmin/Jmax/H1-H4) defeat fingerprint detection. Server config (`awg0.conf`) regenerated by new `cmd/api/awg_sync.go` hooked into existing `RequestSync` orchestrator; reloaded via `wg syncconf` for zero-downtime. Plan-gated via new `plans.amnezia_wg_enabled` column (`false` default). Subscription emits `amneziawg://<base64-config>` URI as first entry (priority 0) for users on enabled plans. Naming reshape: shrink Berëza from 4 FP variants to 2 (chrome/safari only — Reality TCP shares one inbound, so 4-FP defense-in-depth was overkill).

**Tech Stack:** Go 1.25+, PostgreSQL 16, `golang.org/x/crypto/curve25519` for WireGuard keys, React 19 + Vite (admin), amneziawg-go binary from upstream releases, systemd, ufw.

  ```go
  package biz

  import (
      "crypto/rand"
      "database/sql"
      "encoding/base64"
      "encoding/binary"
      "encoding/json"
      "errors"
      "fmt"
      "math/big"
      "net"
      "time"

      "github.com/heyearth/backend/internal/db"
      "golang.org/x/crypto/curve25519"
  )

  // AWGCPSParams — Custom Protocol Settings per user. Each peer gets unique
  // values so DPI can't fingerprint "all AmneziaWG users share signature X".
  //
  // Generation ranges (see generateCPSParams):
  //   Jc: 3..10           — number of junk packets sent BEFORE handshake
  //   Jmin: 50..500       — junk packet min size in bytes
  //   Jmax: 500..1500     — junk packet max size in bytes (must be > Jmin)
  //   S1: 15..150         — pad bytes prepended to init packet
  //   S2: 15..150         — pad bytes appended to init packet
  //                         (S1+S2 < 1280 to stay below QUIC-class MTU)
  //   H1..H4: random uint32 — magic header values overriding WG defaults
  type AWGCPSParams struct {
      Jc   int    `json:"jc"`
      Jmin int    `json:"jmin"`
      Jmax int    `json:"jmax"`
      S1   int    `json:"s1"`
      S2   int    `json:"s2"`
      H1   uint32 `json:"h1"`
      H2   uint32 `json:"h2"`
      H3   uint32 `json:"h3"`
      H4   uint32 `json:"h4"`
  }

  // AWGConfig — fully-populated user AmneziaWG config ready for serialization
  // into a WG INI block by cmd/api/client_api.go::buildAmneziaWGURI.
  type AWGConfig struct {
      UserPrivKey  string       // base64, 32 bytes
      UserPubKey   string       // base64, 32 bytes
      UserPSK      string       // base64, 32 bytes (Q on init packet)
      ServerPubKey string       // base64, 32 bytes
      CPSParams    AWGCPSParams // per-user random
      IPAddress    string       // "10.66.66.42" — assigned slot in /24
      Endpoint     string       // "<main_host>:51820" — Hub UDP listener
  }

  // generateKeyPair returns base64-encoded curve25519 keypair.
  // Follows the WireGuard scheme: 32 random bytes → clamp lower 3 bits +
  // top bit per RFC 7748 → curve25519.X25519 on the base point.
  func generateKeyPair() (privBase64, pubBase64 string, err error) {
      priv := make([]byte, curve25519.ScalarSize) // 32
      if _, err := rand.Read(priv); err != nil {
          return "", "", fmt.Errorf("rand.Read priv: %w", err)
      }
      // RFC 7748 clamping for X25519:
      priv[0] &= 248
      priv[31] &= 127
      priv[31] |= 64

      pub, err := curve25519.X25519(priv, curve25519.Basepoint)
      if err != nil {
          return "", "", fmt.Errorf("curve25519.X25519: %w", err)
      }
      return base64.StdEncoding.EncodeToString(priv),
          base64.StdEncoding.EncodeToString(pub), nil
  }

  // generatePresharedKey — 32 random bytes, base64-encoded. AmneziaWG accepts
  // the same Q (PSK) format as upstream WireGuard.
  func generatePresharedKey() (string, error) {
      buf := make([]byte, 32)
      if _, err := rand.Read(buf); err != nil {
          return "", fmt.Errorf("rand.Read psk: %w", err)
      }
      return base64.StdEncoding.EncodeToString(buf), nil
  }

  // randomIntInRange returns a uniformly random int in [min, max] inclusive.
  // Uses crypto/rand via math/big.Int — overkill for non-cryptographic JC/Jmin
  // values but keeps the entire awg.go consistent with crypto/rand and avoids
  // pulling in math/rand which would need seeding.
  func randomIntInRange(min, max int) (int, error) {
      if max < min {
          return 0, fmt.Errorf("invalid range [%d, %d]", min, max)
      }
      span := big.NewInt(int64(max - min + 1))
      n, err := rand.Int(rand.Reader, span)
      if err != nil {
          return 0, err
      }
      return min + int(n.Int64()), nil
  }

  // randomUint32 — 4 random bytes interpreted as big-endian uint32.
  func randomUint32() (uint32, error) {
      var buf [4]byte
      if _, err := rand.Read(buf[:]); err != nil {
          return 0, err
      }
      return binary.BigEndian.Uint32(buf[:]), nil
  }

  // generateCPSParams produces a fresh random CPS bundle satisfying the
  // constraints from the spec (Jmax > Jmin, S1+S2 < 1280, H1..H4 distinct
  // sources of entropy). On any rand failure it returns an error rather than
  // a partially-populated struct.
  func generateCPSParams() (AWGCPSParams, error) {
      var p AWGCPSParams
      var err error

      if p.Jc, err = randomIntInRange(3, 10); err != nil {
          return p, err
      }
      if p.Jmin, err = randomIntInRange(50, 500); err != nil {
          return p, err
      }
      // Jmax must satisfy Jmax > Jmin. Range floor = Jmin+1, ceiling = 1500.
      jmaxFloor := p.Jmin + 1
      if jmaxFloor > 1500 {
          jmaxFloor = 1500
      }
      if p.Jmax, err = randomIntInRange(jmaxFloor, 1500); err != nil {
          return p, err
      }
      // S1+S2 < 1280: pick S1 freely in 15..150, then bound S2 ceiling at
      // min(150, 1279-S1). Floor stays 15.
      if p.S1, err = randomIntInRange(15, 150); err != nil {
          return p, err
      }
      s2Ceiling := 150
      if maxByConstraint := 1279 - p.S1; maxByConstraint < s2Ceiling {
          s2Ceiling = maxByConstraint
      }
      if p.S2, err = randomIntInRange(15, s2Ceiling); err != nil {
          return p, err
      }

      if p.H1, err = randomUint32(); err != nil {
          return p, err
      }
      if p.H2, err = randomUint32(); err != nil {
          return p, err
      }
      if p.H3, err = randomUint32(); err != nil {
          return p, err
      }
      if p.H4, err = randomUint32(); err != nil {
          return p, err
      }
      return p, nil
  }

  // awgPoolBase is the network prefix for the per-user IPv4 pool.
  // .1 is reserved for the Hub-side awg0 interface; .2-.254 are available
  // for peers; .255 is broadcast.
  const (
      awgPoolPrefix    = "10.66.66."
      awgPoolFirstHost = 2   // first available peer slot
      awgPoolLastHost  = 254 // last available peer slot
  )

  // ErrAWGPoolExhausted — returned from allocateUserIP when all 253 slots are
  // in use. MVP cap; future migration extends pool to 10.66.0.0/16.
  var ErrAWGPoolExhausted = errors.New("amneziawg pool 10.66.66.0/24 exhausted")

  // allocateUserIP picks the lowest-numbered unused slot in 10.66.66.0/24.
  // Must run inside a transaction with FOR UPDATE-style isolation (we use
  // the partial unique index on users(awg_ip_address) for collision safety
  // and a simple lowest-free scan for picking).
  //
  // O(N) in the number of currently-allocated IPs — acceptable for MVP cap
  // of 253. When we expand to /16 (65k slots) this should switch to a
  // bitmap or generate_series sql trick.
  func allocateUserIP(tx *sql.Tx) (string, error) {
      rows, err := tx.Query(`
          SELECT awg_ip_address FROM users
          WHERE awg_ip_address IS NOT NULL
      `)
      if err != nil {
          return "", fmt.Errorf("scan used ips: %w", err)
      }
      defer rows.Close()

      used := make(map[string]struct{})
      for rows.Next() {
          var ip string
          if err := rows.Scan(&ip); err != nil {
              return "", err
          }
          used[ip] = struct{}{}
      }
      if err := rows.Err(); err != nil {
          return "", err
      }

      for octet := awgPoolFirstHost; octet <= awgPoolLastHost; octet++ {
          candidate := fmt.Sprintf("%s%d", awgPoolPrefix, octet)
          if _, taken := used[candidate]; !taken {
              // Sanity check: ensure result is a valid IPv4 (should always be).
              if net.ParseIP(candidate).To4() == nil {
                  continue
              }
              return candidate, nil
          }
      }
      return "", ErrAWGPoolExhausted
  }

  // GetServerAWGKeys returns the Hub's WG identity (private+public base64).
  // Lazy-init: on first call generates a fresh keypair and stores both halves
  // in app_settings under awg_server_private_key / awg_server_public_key.
  // Subsequent calls return the cached values.
  //
  // Mirrors the GetHysteria2ObfsPassword shape but uses two settings keys.
  func GetServerAWGKeys() (privKey, pubKey string, err error) {
      privKey = GetSettingOrDefault("awg_server_private_key", "")
      pubKey = GetSettingOrDefault("awg_server_public_key", "")
      if privKey != "" && pubKey != "" {
          return privKey, pubKey, nil
      }

      privKey, pubKey, err = generateKeyPair()
      if err != nil {
          return "", "", fmt.Errorf("generate server keypair: %w", err)
      }
      if err := SetSetting("awg_server_private_key", privKey); err != nil {
          return "", "", fmt.Errorf("persist server priv: %w", err)
      }
      if err := SetSetting("awg_server_public_key", pubKey); err != nil {
          return "", "", fmt.Errorf("persist server pub: %w", err)
      }
      return privKey, pubKey, nil
  }

  // GetUserAWGConfig returns a fully-populated AmneziaWG config for the user,
  // generating + persisting state on first call and returning the existing
  // state on subsequent calls (idempotent).
  //
  // Atomicity: keys + PSK + CPS + IP are written inside a single transaction
  // so a crash mid-call never leaves a user with partial state. The partial
  // unique index on users(awg_ip_address) protects against concurrent calls
  // for different users racing on the same slot — the second tx will fail
  // with a unique-violation and the caller can retry.
  //
  // The "existing" check uses awg_private_key — if non-empty, all five
  // columns are populated (atomic invariant).
  func GetUserAWGConfig(userID string) (*AWGConfig, error) {
      user, err := GetOrCreateUser(userID)
      if err != nil {
          return nil, fmt.Errorf("resolve user: %w", err)
      }

      serverPriv, serverPub, err := GetServerAWGKeys()
      if err != nil {
          return nil, err
      }
      _ = serverPriv // server priv stays Hub-side; only pub goes to client

      tx, err := db.DB.Begin()
      if err != nil {
          return nil, fmt.Errorf("begin tx: %w", err)
      }
      defer tx.Rollback()

      var (
          privKey, pubKey, psk, ip sql.NullString
          cpsJSON                  sql.NullString
      )
      err = tx.QueryRow(`
          SELECT COALESCE(awg_private_key, ''),
                 COALESCE(awg_public_key, ''),
                 COALESCE(awg_preshared_key, ''),
                 COALESCE(awg_ip_address, ''),
                 COALESCE(awg_cps_params::text, '')
          FROM users WHERE id = $1
          FOR UPDATE
      `, user.ID).Scan(&privKey, &pubKey, &psk, &ip, &cpsJSON)
      if err != nil {
          return nil, fmt.Errorf("load awg state: %w", err)
      }

      // Existing-state path: all five fields populated → just decode + return.
      if privKey.Valid && privKey.String != "" {
          var cps AWGCPSParams
          if cpsJSON.Valid && cpsJSON.String != "" {
              if err := json.Unmarshal([]byte(cpsJSON.String), &cps); err != nil {
                  return nil, fmt.Errorf("decode cached cps: %w", err)
              }
          }
          // tx is read-only on this path; commit is cheap and frees the row lock.
          if err := tx.Commit(); err != nil {
              return nil, fmt.Errorf("commit (read-only): %w", err)
          }
          return &AWGConfig{
              UserPrivKey:  privKey.String,
              UserPubKey:   pubKey.String,
              UserPSK:      psk.String,
              ServerPubKey: serverPub,
              CPSParams:    cps,
              IPAddress:    ip.String,
              Endpoint:     awgEndpoint(),
          }, nil
      }

      // First-time path: generate everything atomically.
      newPriv, newPub, err := generateKeyPair()
      if err != nil {
          return nil, err
      }
      newPSK, err := generatePresharedKey()
      if err != nil {
          return nil, err
      }
      newCPS, err := generateCPSParams()
      if err != nil {
          return nil, err
      }
      cpsBytes, err := json.Marshal(newCPS)
      if err != nil {
          return nil, fmt.Errorf("marshal cps: %w", err)
      }
      newIP, err := allocateUserIP(tx)
      if err != nil {
          return nil, err
      }

      if _, err := tx.Exec(`
          UPDATE users
             SET awg_private_key   = $1,
                 awg_public_key    = $2,
                 awg_preshared_key = $3,
                 awg_cps_params    = $4::jsonb,
                 awg_ip_address    = $5
           WHERE id = $6
      `, newPriv, newPub, newPSK, string(cpsBytes), newIP, user.ID); err != nil {
          return nil, fmt.Errorf("persist awg state: %w", err)
      }
      if err := tx.Commit(); err != nil {
          return nil, fmt.Errorf("commit: %w", err)
      }

      return &AWGConfig{
          UserPrivKey:  newPriv,
          UserPubKey:   newPub,
          UserPSK:      newPSK,
          ServerPubKey: serverPub,
          CPSParams:    newCPS,
          IPAddress:    newIP,
          Endpoint:     awgEndpoint(),
      }, nil
  }

  // awgEndpoint returns the host:port string clients dial. Host comes from
  // app_settings.main_server_host (set during --setup-main), port is the
  // fixed AmneziaWG UDP listener at 51820. If host setting is empty (fresh
  // dev DB), returns ":51820" — caller (URI builder) is responsible for
  // detecting empty host and skipping emit.
  func awgEndpoint() string {
      host := GetSettingOrDefault("main_server_host", "")
      return host + ":51820"
  }

  // awgConfigVersionTick is a placeholder hook for cmd/api/awg_sync.go (T5)
  // to bump after each per-user state write so the orchestrator can detect
  // changes. Implementation lives in awg_sync.go to keep biz package free
  // of file/systemd side effects. We intentionally do not call it here:
  // T5 will subscribe to NotifySubscriptionChange and recheck users itself.
  //
  // Marker for cross-task wiring:
  var _ = time.Now // ensure time import remains stable for future use
  ```

### Task 5: cmd/api/awg_sync.go — generate awg0.conf + reload

**Goal.** Stand up the runtime sync loop that translates current
plan/subscription state into `/opt/heyearth/awg/awg0.conf` and reloads the
`awg.service` systemd unit. Architectural mirror of
`cmd/api/hysteria2_sync.go`: same `RequestXxxSync()` debounced pattern, same
`SyncXxxConfig()` worker, same idempotence-by-content-equality short-circuit,
same atomic-write-then-rename, same biz-layer hook (`biz.AWGSyncFn = ...`).

The key difference vs Hysteria2: AmneziaWG config is **per-peer**, not global.
Each enabled user with a `awg_public_key` becomes a `[Peer]` block with their
own CPS obfuscation params (Jc/Jmin/Jmax/S1/S2/H1..H4 from
`users.awg_cps_params`). We never generate keypairs server-side from this
function — that is the responsibility of the user-facing registration handler
(separate task in Phase 3); this file consumes already-stored keys.

Reload mechanism: `wg syncconf awg0 /opt/heyearth/awg/awg0.conf` is the
preferred path because it applies peer diffs without dropping the interface or
churning existing tunnels. **However** `wg syncconf` only works when the `awg0`
TUN interface is already up — on cold boot or after binary upgrade the
interface does not exist yet, so we fall back to `systemctl restart awg` which
recreates the interface from scratch. (`systemctl reload awg` is not supported
by amneziawg-go.) The cost of the fallback is ~1 second of downtime for all
peers; acceptable on cold-start, not acceptable for steady-state peer
add/remove churn — hence the layered approach.

```go
// server/backend/cmd/api/awg_sync.go
package main

// AmneziaWG (Palma) server config sync.
//
// Architecture: amneziawg-go runs as its own systemd unit (awg.service) on
// the Hub, listening UDP :51820. Per-user keys + CPS obfuscation params are
// stored in PostgreSQL (users.awg_public_key, users.awg_preshared_key,
// users.awg_cps_params, users.awg_ip_address). On every plan/subscription
// mutation, biz.NotifySubscriptionChange fans out to RequestAWGSync (wired
// in main.go alongside Xray + Hysteria2). We debounce 2s, then regenerate
// /opt/heyearth/awg/awg0.conf and apply via `wg syncconf` (no-downtime) or
// `systemctl restart awg` (cold-start fallback).
//
// Mirrors cmd/api/hysteria2_sync.go in structure, idempotence, and error
// reporting (app_settings.awg_last_error → admin UI).
//
// Out-of-scope for MVP (per spec): port-hopping, per-peer bandwidth caps,
// rotation of server keys. Server keypair is initialised once via
// biz.GetServerAWGKeys (lazy init on first sync).

import (
	"bytes"
	"database/sql"
	"fmt"
	"log"
	"os"
	"os/exec"
	"strconv"
	"strings"
	"sync"
	"time"

	"github.com/heyearth/backend/internal/biz"
	"github.com/heyearth/backend/internal/db"
)

const (
	awgConfigPath = "/opt/heyearth/awg/awg0.conf"
	awgConfigDir  = "/opt/heyearth/awg"
	awgInterface  = "awg0"
	awgListenPort = 51820
	awgServerIP   = "10.66.66.1/24"
)

var (
	awgSyncMu     sync.Mutex
	awgDebounceMu sync.Mutex
	awgDebounce   *time.Timer
)

// RequestAWGSync debounces sync requests so a burst of plan/subscription
// changes results in a single config regeneration. 2s window matches the
// Xray and Hysteria2 debounce so all three sync loops land within the same
// burst window.
func RequestAWGSync() {
	awgDebounceMu.Lock()
	defer awgDebounceMu.Unlock()
	if awgDebounce != nil {
		awgDebounce.Stop()
	}
	awgDebounce = time.AfterFunc(2*time.Second, func() {
		if err := SyncAWGConfig(); err != nil {
			log.Printf("[awg-sync] debounced sync error: %v", err)
			recordAWGSyncError(err)
		}
	})
}

// SyncAWGConfig regenerates /opt/heyearth/awg/awg0.conf and reloads the service.
// Idempotent: if the generated content matches what's on disk, no reload
// happens. Returns nil with a log message when the awg directory does not
// exist (dev environment without --setup-awg run yet) — Xray + Hysteria2 keep
// working independently.
func SyncAWGConfig() error {
	awgSyncMu.Lock()
	defer awgSyncMu.Unlock()

	// Skip cleanly if amneziawg-go isn't installed. We probe the install dir,
	// not $PATH, because amneziawg-go is installed under /opt and not symlinked
	// into /usr/local/bin (unlike hysteria).
	if _, err := os.Stat(awgConfigDir); os.IsNotExist(err) {
		return nil
	}

	// Server keypair — lazy-init on first sync. biz.GetServerAWGKeys generates
	// + stores a fresh Curve25519 keypair in app_settings on the very first
	// call; subsequent calls return the cached values. Server pubkey is also
	// surfaced to clients via the per-user provisioning endpoint (Phase 3).
	serverPriv, _, err := biz.GetServerAWGKeys()
	if err != nil {
		return fmt.Errorf("get server awg keys: %w", err)
	}

	// Pull all eligible peers. Eligibility = (a) plan flag amnezia_wg_enabled,
	// (b) active subscription not yet expired, (c) user has gone through the
	// AWG registration handler so awg_public_key is populated. Users on AWG-
	// enabled plans who haven't yet hit the registration endpoint are simply
	// skipped — they'll show up in the next sync after they fetch their config.
	rows, err := db.DB.Query(`
		SELECT u.awg_public_key,
		       COALESCE(u.awg_preshared_key, ''),
		       COALESCE(u.awg_cps_params, '{}'::jsonb)::text,
		       u.awg_ip_address
		FROM users u
		JOIN user_subscriptions us ON us.user_id = u.id
		JOIN plans p ON p.id = us.plan_id
		WHERE p.amnezia_wg_enabled = TRUE
		  AND us.status = 'active'
		  AND us.valid_until > NOW()
		  AND u.awg_public_key IS NOT NULL
		  AND u.awg_public_key <> ''
		  AND u.awg_ip_address IS NOT NULL
	`)
	if err != nil {
		return fmt.Errorf("select awg peers: %w", err)
	}
	defer rows.Close()

	var peers []awgPeer
	for rows.Next() {
		var p awgPeer
		var cpsJSON string
		var ip sql.NullString
		if err := rows.Scan(&p.PublicKey, &p.PresharedKey, &cpsJSON, &ip); err != nil {
			return fmt.Errorf("scan peer row: %w", err)
		}
		if !ip.Valid || ip.String == "" {
			continue
		}
		p.AllowedIP = ip.String
		// CPS params: parse JSON object into per-peer obfuscation fields.
		// Malformed JSON → fall back to defaults so a single bad row doesn't
		// kill the whole sync.
		p.CPS = parseAWGCPSParams(cpsJSON)
		peers = append(peers, p)
	}
	if err := rows.Err(); err != nil {
		return fmt.Errorf("iterate peer rows: %w", err)
	}

	conf := renderAWGConfig(serverPriv, peers)

	// No-op short-circuit. If the on-disk content already matches, skip the
	// rename + reload entirely. This is the steady-state hot path (sync runs
	// every 5 min from the background loop even when nothing changed).
	if existing, err := os.ReadFile(awgConfigPath); err == nil {
		if bytes.Equal(existing, []byte(conf)) {
			return nil
		}
	}

	// Atomic write: write to .tmp, then rename. amneziawg-go does not provide
	// a syntactic --check mode for config files, so unlike hysteria2_sync.go
	// we cannot validate before rename. The format is simple INI; the
	// fallback reload (systemctl restart awg) will fail visibly if the file
	// is bad, and recordAWGSyncError will surface that into app_settings for
	// admin UI.
	tmpPath := awgConfigPath + ".tmp"
	if err := os.WriteFile(tmpPath, []byte(conf), 0o640); err != nil {
		return fmt.Errorf("write tmp awg config: %w", err)
	}
	if err := os.Rename(tmpPath, awgConfigPath); err != nil {
		_ = os.Remove(tmpPath)
		return fmt.Errorf("rename awg config: %w", err)
	}
	// Ownership: amnezia-wg:amnezia-wg 0640 to match the systemd unit's
	// expected file permissions (filesystem owner, not service runas).
	// Best-effort — chown failure does NOT abort sync; log only.
	if err := chownToAmneziaWG(awgConfigPath); err != nil {
		log.Printf("[awg-sync] chown awg config: %v (continuing)", err)
	}

	// Reload. Layered strategy:
	//   1. `wg syncconf awg0 <file>` — fast peer diff, no interface churn.
	//      Requires awg0 to already be up. Will fail with "device does not
	//      exist" on cold-start.
	//   2. `systemctl restart awg` — recreates the interface from scratch.
	//      ~1s of downtime for all peers; acceptable on cold-start, suboptimal
	//      for steady-state churn. Used as fallback.
	// We try (1) first and only fall back to (2) on failure.
	if out, err := exec.Command("wg", "syncconf", awgInterface, awgConfigPath).CombinedOutput(); err != nil {
		log.Printf("[awg-sync] wg syncconf failed (%v: %s) — falling back to systemctl restart awg",
			err, strings.TrimSpace(string(out)))
		if out2, err2 := exec.Command("systemctl", "restart", "awg").CombinedOutput(); err2 != nil {
			return fmt.Errorf("restart awg: %w (%s)", err2, strings.TrimSpace(string(out2)))
		}
	}

	// Bump config_version so admin UI / clients can detect changes.
	cur := biz.GetSettingOrDefault("awg_config_version", "1")
	if n := atoiSafe(cur); n > 0 {
		_ = biz.SetSetting("awg_config_version", fmt.Sprintf("%d", n+1))
	}
	_ = biz.SetSetting("awg_last_sync_at", fmt.Sprintf("%d", time.Now().Unix()))
	_ = biz.SetSetting("awg_last_error", "")
	_ = biz.SetSetting("awg_peer_count", fmt.Sprintf("%d", len(peers)))

	log.Printf("[awg-sync] config updated: %d peers", len(peers))
	return nil
}

// recordAWGSyncError stashes the error into app_settings so admin UI can
// surface it without reading journalctl. Mirrors hysteria2 pattern.
func recordAWGSyncError(err error) {
	if err == nil {
		return
	}
	_ = biz.SetSetting("awg_last_error", err.Error())
}

// awgPeer is the wire-format struct fed into the config template.
type awgPeer struct {
	PublicKey    string
	PresharedKey string
	AllowedIP    string // single IP, /32 will be appended by the template
	CPS          awgCPS
}

// awgCPS holds the per-peer obfuscation params. Field names match the
// AmneziaWG ini config keys exactly.
type awgCPS struct {
	Jc   int
	Jmin int
	Jmax int
	S1   int
	S2   int
	H1   int
	H2   int
	H3   int
	H4   int
}

// parseAWGCPSParams pulls the obfuscation fields out of the JSONB blob stored
// in users.awg_cps_params. Missing / malformed fields fall back to "reasonable
// AmneziaWG defaults" so a single bad row doesn't kill the whole sync. The
// authoritative param generator (Phase 3 — user registration) produces values
// in known ranges; this parser is defensive against legacy / mutated rows.
func parseAWGCPSParams(jsonText string) awgCPS {
	// Default values per AmneziaWG project docs (sane MVP defaults — Phase 3
	// will randomise per-peer for traffic-shape diversity).
	def := awgCPS{
		Jc: 4, Jmin: 50, Jmax: 1000,
		S1: 0, S2: 0,
		H1: 1, H2: 2, H3: 3, H4: 4,
	}
	if jsonText == "" || jsonText == "{}" {
		return def
	}
	var m map[string]int
	if err := jsonUnmarshalCompat([]byte(jsonText), &m); err != nil {
		log.Printf("[awg-sync] parse cps params: %v (using defaults)", err)
		return def
	}
	get := func(key string, fallback int) int {
		if v, ok := m[key]; ok {
			return v
		}
		return fallback
	}
	return awgCPS{
		Jc:   get("Jc", def.Jc),
		Jmin: get("Jmin", def.Jmin),
		Jmax: get("Jmax", def.Jmax),
		S1:   get("S1", def.S1),
		S2:   get("S2", def.S2),
		H1:   get("H1", def.H1),
		H2:   get("H2", def.H2),
		H3:   get("H3", def.H3),
		H4:   get("H4", def.H4),
	}
}

// renderAWGConfig produces the awg0.conf content. Deterministic ordering so
// bytes.Equal short-circuit works across invocations — peers are emitted in
// the order returned by the SELECT (ORDER BY u.id implicit via PK insert
// order; if you change the SELECT, add an explicit ORDER BY).
func renderAWGConfig(serverPriv string, peers []awgPeer) string {
	var b strings.Builder
	b.WriteString("# /opt/heyearth/awg/awg0.conf\n")
	b.WriteString("# Generated by heyearth-api awg_sync.go. DO NOT EDIT BY HAND.\n")
	b.WriteString("[Interface]\n")
	fmt.Fprintf(&b, "PrivateKey = %s\n", serverPriv)
	fmt.Fprintf(&b, "ListenPort = %d\n", awgListenPort)
	fmt.Fprintf(&b, "Address = %s\n", awgServerIP)
	b.WriteString("\n")

	for _, p := range peers {
		b.WriteString("[Peer]\n")
		fmt.Fprintf(&b, "PublicKey = %s\n", p.PublicKey)
		if p.PresharedKey != "" {
			fmt.Fprintf(&b, "PresharedKey = %s\n", p.PresharedKey)
		}
		// AllowedIPs accepts a CIDR; user IP is stored as a bare /32 host
		// address in users.awg_ip_address. Append /32 if not already a CIDR.
		ip := p.AllowedIP
		if !strings.Contains(ip, "/") {
			ip = ip + "/32"
		}
		fmt.Fprintf(&b, "AllowedIPs = %s\n", ip)
		// CPS obfuscation params — these are per-peer in AmneziaWG (unlike
		// classic WireGuard which has no obfuscation at all).
		fmt.Fprintf(&b, "Jc = %d\n", p.CPS.Jc)
		fmt.Fprintf(&b, "Jmin = %d\n", p.CPS.Jmin)
		fmt.Fprintf(&b, "Jmax = %d\n", p.CPS.Jmax)
		fmt.Fprintf(&b, "S1 = %d\n", p.CPS.S1)
		fmt.Fprintf(&b, "S2 = %d\n", p.CPS.S2)
		fmt.Fprintf(&b, "H1 = %d\n", p.CPS.H1)
		fmt.Fprintf(&b, "H2 = %d\n", p.CPS.H2)
		fmt.Fprintf(&b, "H3 = %d\n", p.CPS.H3)
		fmt.Fprintf(&b, "H4 = %d\n", p.CPS.H4)
		b.WriteString("\n")
	}

	return b.String()
}

// chownToAmneziaWG looks up the amnezia-wg system user (created by
// cmd/deploy/amneziawg_hub.go) and sets file ownership. Best-effort.
func chownToAmneziaWG(path string) error {
	// We do the lookup inline rather than caching because the user could be
	// recreated mid-process by a re-run of --setup-awg. Cheap enough.
	out, err := exec.Command("id", "-u", "amnezia-wg").CombinedOutput()
	if err != nil {
		return fmt.Errorf("lookup uid: %w (%s)", err, strings.TrimSpace(string(out)))
	}
	uid, err := strconv.Atoi(strings.TrimSpace(string(out)))
	if err != nil {
		return fmt.Errorf("parse uid: %w", err)
	}
	out, err = exec.Command("id", "-g", "amnezia-wg").CombinedOutput()
	if err != nil {
		return fmt.Errorf("lookup gid: %w (%s)", err, strings.TrimSpace(string(out)))
	}
	gid, err := strconv.Atoi(strings.TrimSpace(string(out)))
	if err != nil {
		return fmt.Errorf("parse gid: %w", err)
	}
	if err := os.Chown(path, uid, gid); err != nil {
		return fmt.Errorf("chown: %w", err)
	}
	if err := os.Chmod(path, 0o640); err != nil {
		return fmt.Errorf("chmod: %w", err)
	}
	return nil
}

// StartAWGSyncLoop kicks off an initial sync and a 5-minute periodic sync.

		log.Println("[awg-sync] /opt/heyearth/awg not present, sync loop disabled (run --setup-awg)")
```

**Ordering rationale.** The bootstrap order matters when a deploy is racing
the very first sync of every backend. By running them sequentially in this
order — Xray → Hysteria2 → AWG → Hysteria2 stats — we guarantee that:

1. Xray sync writes its config and Reality keys before any other sync looks
   at app_settings (some keys are shared via biz cache).
2. Hysteria2 sync runs after Xray so the obfs_password app_setting is
   guaranteed initialised by the Xray sync seeder (it isn't actually
   shared, but ordering by deploy age is stable).
3. AWG sync runs last among the config-writing loops because it has the
   smallest blast radius (its own dir, its own service) — if it crashes
   on first run, Xray + Hysteria2 are already healthy.
4. Hysteria2 stats collector runs after both server-config loops are done
   so it never queries a not-yet-listening trafficStats endpoint.

Each `Start*SyncLoop()` schedules its periodic ticker on a goroutine, so
the actual sequencing is "initial sync is sequential, periodic refreshes
are independent" — adequate isolation.
