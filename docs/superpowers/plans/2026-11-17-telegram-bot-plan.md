# Telegram: бот-кабинет, канал, новости, поддержка — план (17.11.2026)

**Цель.** Сделать второй бот, для пользователей. Он полностью повторяет личный кабинет и присылает уведомления. Дополнительно:
- канал для новостей, советов и акций, куда бот публикует посты;
- рассылка новостей из админки одной кнопкой: в канал, подписчикам бота, в ленту кабинета и объявлением в Happ;
- поддержка: человек пишет с сайта или из бота, владелец отвечает в админке или прямо из своего Telegram, ответ приходит на сайт и в бот.

Бот для алертов владельца уже есть (`cmd/api/alerts.go`). Пользовательский бот — отдельный, со своим токеном.

## Решения владельца (17.11)

| Вопрос | Решение |
|---|---|
| Оплата | Внутри бота и Mini App ничего не продаём. «Пополнить» и «Оплатить» открывают сайт во внешнем браузере (`openLink`), там ЮKassa, как сейчас. Причина — правило Telegram: цифровые услуги внутри бота или Mini App можно продавать только за Stars, иначе «Telegram cannot display your bot or mini-app to mobile users» (core.telegram.org/bots/payments-stars). |
| Кабинет | Mini App (тот же кабинет на «Каноне», вход по Telegram) + чат-бот с быстрыми кнопками и уведомлениями. |
| Поддержка | Раздел в админке + уведомление владельцу в бот алертов. Ответить можно прямо ответом на это сообщение. Ответ доходит пользователю и на сайт, и в бот. |
| Новости | Одна публикация уходит сразу во все выбранные места: телеграм-канал, бот (всем / с подпиской / без подписки), лента «Новости» в кабинете, объявление в Happ. |

## Ограничения (обязательно)

- **Hub не достаёт до Telegram.** api.telegram.org, DC и middle-end из российского датацентра Hub не отвечают — см. память `project_tg_webproxy`. Все вызовы Bot API идут тем же маршрутом, что алерты: `telegramRoute` в `cmd/api/alerts.go` — прямой путь с переходом на exit.
  - Этот маршрут выносится в общий пакет `internal/telegram`, и оба бота пользуются им.
  - Обновления бот получает long polling (`getUpdates`) через тот же маршрут, без вебхуков: входящие соединения из сетей Telegram к Hub тоже могут резаться.
- **Telegram Bot API актуальной версии** (на 17.11.2026 — 10.4 от 09.11.2026). Перед кодом прочитать https://core.telegram.org/bots/api, https://core.telegram.org/bots/webapps и https://core.telegram.org/bots/api-changelog.
  - Через WebFetch страница может обрываться — повторить или открыть по разделам.
  - Использовать то, что делает бот современным и полезным:
    - стили кнопок (9.4);
    - темы в личных чатах для потока поддержки (9.3/9.4) — если подходит;
    - Rich Messages (10.1) и виджеты (10.4) для новостей — если поддерживаются клиентами;
    - эфемерные сообщения (10.2) для подсказок;
    - в Mini App: полноэкранный режим, кнопки `MainButton` и `BackButton`, haptics, safe areas, `addToHomeScreen`, проверка `initData`.
- **Токены** обоих ботов лежат в `app_settings`, в админке они только для записи. Их никогда не логировать и не печатать.
- **Репозиторий публичный:** никаких токенов, id чатов и адресов в коде, тестах и документах.
- **Интерфейс сайта и Mini App — строго по «Канону».** Новый элемент, экран или текст сначала записывается в `site/design-system/hiearth-canon/spec/`, потом идёт в код. STOP catches из CLAUDE.md. Слова «VPN» нет.
- **Админка** — по своему theme-lock.
- **Сообщения реальным людям.** Тесты — только на Telegram-аккаунте владельца. Первый реальный пост в канал и первая рассылка пользователям — только после явного «да» владельца в чате, с показом текста.

## Задачи

### TG1. `internal/telegram` — клиент Bot API
- Типизированное подмножество методов: `getMe`, `getUpdates`, `sendMessage`/`sendPhoto` (+ `reply_markup`), `editMessageText`, `deleteMessage`, `answerCallbackQuery`, `setMyCommands`, `setChatMenuButton`, `setMyDescription`/`setMyShortDescription`, `getChat`, `getChatMember`, `createForumTopic` (для тем в личном чате, если выбрано), `sendChatAction` и другие по мере нужды.
- Транспорт — маршрут `telegramRoute` (прямой путь с переходом на exit), перенесённый из `alerts.go`. Алерты переходят на пакет без изменения поведения: golden-тест текста.
- Лимиты: глобальный token bucket 25 сообщений/с, 1 сообщение/с на чат. Ответ 429 → ждать `retry_after`. Ответ 403 «bot was blocked» → `users.tg_blocked=true`.
- Поллер: один экземпляр (advisory lock в Postgres), `offset` хранится в `app_settings`, перезапуск ничего не теряет и не дублирует. Сделать на `safely()`, как остальные фоновые циклы.
- Тесты: фейковый транспорт, 429/403, лимиты, порядок `offset`.

### TG2. Связка аккаунтов
- **Миграция.** `users.telegram_id` уже есть, добавить: `telegram_username`, `telegram_linked_at`, `tg_blocked`, `notify_news`, `notify_reminders` (по умолчанию true). Одноразовые токены связки `tg_link_tokens(token_hash, user_id, expires_at)`, срок 10 минут.
- **С сайта.** «Настройки» → «Подключить Telegram» → `t.me/<bot>?start=link_<token>` → бот привязывает аккаунт и отвечает «Готово». Там же — «Отвязать».
- **Новый человек в боте (`/start`)** — Mini App предлагает два варианта:
  - «У меня есть HiEarth ID» — вход по ID и паролю или кнопка «Привязать с сайта»;
  - «Создать новый» — анонимная регистрация как на сайте: ID с «номерком» и «Я сохранил».
- **Рефералы.** `start=ref_<code>` и `startapp=ref_<code>` записывают пригласившего, как ссылка `/r/<code>`.
- **Правило.** Один Telegram-аккаунт привязан максимум к одному пользователю HiEarth. Повторная привязка — только после отвязки.
- Тесты: истёкший или чужой токен, двойная привязка, отвязка.

### TG3. Mini App = кабинет сайта
- **Маршрут `/tg`** — точка входа Mini App. Подключает `telegram-web-app.js` и отправляет `initData` на сервер: `POST /api/v1/auth/telegram`.
- **Сервер проверяет подпись по документации:** `secret = HMAC_SHA256(key="WebAppData", msg=bot_token)`, `hash` = HMAC-SHA256 от data-check-string. Плюс `auth_date` не старше 24 ч.
  - Аккаунт привязан → обычный JWT пользователя.
  - Не привязан → экран из TG2.
- **Кабинет внутри Telegram** — те же страницы «Канона» с режимом Mini App:
  - `BackButton` соответствует истории роутера;
  - главное действие экрана (одна primary-кнопка «Канона») продублировано в `MainButton`, на сайте не меняется;
  - haptics на успех и ошибку;
  - safe-area insets;
  - тёмные цвета заголовка и фона из `--bg` (`setHeaderColor`/`setBackgroundColor`);
  - полноэкранный режим на телефоне.
- **Оплата.** «Пополнить» и «Оплатить» открывают сайт во внешнем браузере (`openLink`) с одноразовым входом: `GET /api/v1/auth/magic/<token>`, 5 минут, одно использование. Человек оказывается на странице оплаты уже авторизованным. Внутри Mini App платёжного виджета нет.
- **Подключение.** `Happ://` и `tg://` ссылки открываются через `openLink`/`openTelegramLink`.
- **Спецификация «Канона».** Раздел «Mini App»: какие экраны есть, как ведут себя кнопки Telegram, чем отличается от сайта.
- Тесты: проверка `initData` по эталонному вектору (подделка, просрочка, чужой бот), magic-токен одноразовый.

### TG4. Чат-бот: кнопки и уведомления
- **Меню бота** (`setMyCommands` + кнопка меню = Mini App):
  - `/start` — приветствие и «Открыть кабинет»;
  - `/status` — подписка, дни, баланс;
  - `/connect` — ссылка подписки и кнопка «Добавить в Happ»;
  - `/wallet` — баланс и «Пополнить на сайте»;
  - `/friend` — реферальная ссылка и «Поделиться»;
  - `/support` — поддержка;
  - `/news` — последние новости;
  - `/settings` — уведомления.
- **Уведомления**, каждое по своему флажку и с кнопкой нужного действия:
  - подписка заканчивается через 3 дня и сегодня;
  - подписка закончилась;
  - автопродление списано / денег не хватает;
  - кошелёк пополнен;
  - бонус за друга;
  - ответ поддержки;
  - новость.

  Сделать на тех же событиях, что письма (E8) и объявления Happ, — без второй копии логики.
- **Тексты** — по `spec/05-content.md`: «вы», без «VPN», ошибки с причиной и действием.
- Тесты: роутер команд, выбор адресатов уведомлений, антидубль.

### TG5. Поддержка
- **Таблицы:**
  - `support_tickets(id, user_id, status open|waiting|answered|closed, created_at, updated_at, last_user_at, last_admin_at)`;
  - `support_messages(id, ticket_id, author user|admin, admin_id, body ≤ 4000, image_path, via site|bot|owner_tg, created_at, read_at)`.
- **Сайт и Mini App.** Кнопка «Поддержка» в шапке кабинета (AppShell) и на странице «Помощь». Страница `/support` — переписка, новое сообщение, картинка до 5 МБ, статус. Всё по «Канону», сначала спецификация.
- **Бот.** «Написать в поддержку»: сообщения в этом режиме уходят в обращение — отдельная тема в личном чате (9.3/9.4), если это удобнее, иначе режим с кнопкой «Закончить».
- **Админка, раздел «Поддержка»:**
  - входящие с фильтрами и счётчиками непрочитанного;
  - переписка;
  - ответ, «Закрыть»;
  - ссылка на карточку пользователя;
  - быстрые ответы — по желанию.
  - Право `support.manage`.
- **Ответ** доставляется в бот (если привязан), появляется на сайте (с отметкой непрочитанного) и уходит письмом (если адрес подтверждён).
- **Владельцу в бот алертов** приходит новое обращение: текст, пользователь, кнопка «Открыть в админке». Ответ на это сообщение (reply) становится ответом в обращении — принимается только из чата алертов владельца. Для этого бот алертов тоже читает `getUpdates` через тот же поллер.
- **Антиспам:** не больше 10 сообщений за 10 минут на пользователя.
- Тесты: весь круг сайт → админ → бот, ответ из Telegram владельца, чужой reply отвергается.

### TG6. Новости и канал
- **Таблицы:**
  - `news_posts(id, title, body — HTML-подмножество Telegram, image_path, button_text, button_url, targets — channel / bot_all / bot_active / bot_inactive / site / happ, happ_days, status draft|scheduled|sending|sent|failed, scheduled_at, created_by, counts)`;
  - `news_deliveries(post_id, user_id, status, message_id, error)`.
- **Админка, раздел «Новости»:**
  - редактор с предпросмотром — как в Telegram и как в кабинете;
  - выбор мест публикации, расписание;
  - «Отправить сейчас» с подтверждением и счётчиком получателей;
  - статистика: доставлено, ошибки, заблокировали бота;
  - правка и удаление — `editMessageText` в канале и в недавних сообщениях бота.
- **Канал:**
  - настройка `tg_channel_id` (@имя или -100…);
  - «Проверить канал» (`getChat` + `getChatMember`: бот — админ с правом публикации);
  - канал создаёт владелец (боты не создают каналы) и добавляет бота админом.
- **Рассылка через бот** идёт очередью ≤ 25 сообщений/с, переживает перезапуск, учитывает `notify_news` и `tg_blocked`. Отписка — кнопкой под новостью и в `/settings`.
- **Лента «Новости» в кабинете** (сайт и Mini App) с отметкой непрочитанного — по «Канону», сначала спецификация.
- **Happ.** Текст объявления в подписке на `happ_days` дней. Личные объявления (продление, кошелёк) важнее новостей. Подписка меняется намеренно, только пока объявление активно — снимок до/после это покажет.
- Тесты: выбор получателей, очередь и 429, отписка, приоритет объявлений.

### TG7. Админка «Telegram»
- **Блок «Бот для пользователей»:**
  - токен (только запись);
  - имя бота — по `getMe`;
  - адрес Mini App (`https://<сайт>/tg`);
  - «Проверить» — `getMe` через маршрут exit;
  - при сохранении бэкенд сам ставит команды, кнопку меню и описание.
- **Блок «Канал»:** id и «Проверить».
- **Блок «Бот алертов»:** существующий, рядом, для понятности.
- **Подсказки владельцу по шагам:** создать бота в @BotFather, вставить токен, создать канал, добавить бота админом, проверить.

## Этапы и проверка

**Этапы:**
- TG-A — TG1–TG3: клиент, поллер, связка, Mini App и вход.
- TG-B — TG4: бот и уведомления.
- TG-C — TG5: поддержка.
- TG-D — TG6–TG7: новости, канал, админка.
- TG-E — документация: CLAUDE.md, память, runbook «Telegram-бот».

**Ревью** — одно на этап.

**Деплой:**
- API — `quick_deploy.go` из чистого worktree, снимок подписок до и после.
- Админка — `quick_admin_web.go`.
- Сайт — `quick_admin_web.go -site`.
- Если SSH к Hub не проходит — `server/backend/scripts/prod/hubfwd.py`.

**Проверка на проде:**
- `getMe` через exit;
- `/start` и Mini App — на аккаунте владельца, после того как он вставит токен;
- связка с сайта;
- поддержка по кругу;
- тестовая новость — только в ленту кабинета; в канал и рассылку — с «да» владельца.

**За владельцем:**
- создать бота в @BotFather и вставить токен в админку;
- создать канал и добавить бота админом;
- вставить токен бота алертов (уже обещал).
