## Problem

После R1+R2+R3 (commits `2da05a3` + `110f5a5` + `945705c`) — Tele2 cell-DPI всё ещё ловит **QUIC patterns** (Hysteria2 «Бамбук») и **TCP+Reality timing** («Дуб» XHTTP). Юзер с Tele2 не может стабильно использовать UDP-based и XHTTP-based профили.

Решение: внедрить **четвёртый protocol family** который TSPU фундаментально не идентифицирует — **AmneziaWG 2.0** (March 2026), WireGuard + Custom Protocol Settings (CPS junk packets imitating HTTPS/garbage). Per research, AmneziaWG — самый эффективный на RU mobile networks в 2026 (наряду с обфусцированным VLESS+Reality).

Параллельно — два quick wins из той же research-таблицы:
- **R4**: XHTTP server-side response chunking — mitigates new RU «freezing» attack на TLS-over-foreign-datacenter connections >15-20KB
- **R5**: добавить мобильные операторские домены (mts.ru/tele2.ru/megafon.ru/beeline.ru) в `direct_route_services` — избежать APN-leak loop

Также: **reshape subscription profile naming** для UX clarity (сократить избыточные FP-варианты Берёзы) и **admin per-plan toggle** для AmneziaWG (как существующий `express_enabled`).

## R7 — AmneziaWG 2.0 architecture

### Server stack

| Component | Path / config |
|---|---|
| Binary | `/opt/heyearth/awg/amneziawg-go` (userspace, Go static) |
| Systemd unit | `awg.service` listens UDP :51820 |
| Config file | `/opt/heyearth/awg/awg0.conf` (WG INI format, generated by `awg_sync.go`) |
| Server keys | `app_settings.awg_server_private_key` / `awg_server_public_key` (auto-gen at first sync) |
| Per-user keys | `users.awg_private_key`, `users.awg_public_key`, `users.awg_preshared_key` |
| Per-user CPS | `users.awg_cps_params JSONB` — `{jc, jmin, jmax, s1, s2, h1, h2, h3, h4}` random per user |
| Per-user IP | `users.awg_ip_address VARCHAR(16)` — pool 10.66.66.0/24 (254 max for MVP) |

**Lazy init**: на первый emit Пальма URI для юзера → `biz.GetUserAWGConfig(userID)` генерирует ключи + CPS + IP. Идемпотентно — повторный вызов возвращает existing.

**Config regeneration**: hooked into existing `RequestSync` orchestrator (`cmd/api/main.go`). При user.amnezia_wg_enabled change → rebuild `awg0.conf` → `wg syncconf awg0` zero-downtime reload OR `systemctl reload awg` fallback.

### CPS (Custom Protocol Settings) — anti-DPI магия

AmneziaWG 2.0 vs vanilla WireGuard:
- **Junk packets** (Jc): N empty packets ДО handshake (camouflage)
- **Junk size**: Jmin/Jmax байт диапазон
- **Magic headers** (H1-H4): mimic HTTPS/garbage signatures, не WG default
- **Init packet padding** (S1/S2): pad initial handshake packet

**Per-user random CPS** = каждый юзер looks unique → DPI cannot fingerprint "all AmneziaWG users share signature X".

Generation algorithm (in `biz/awg.go::generateCPSParams`):
```
jc        = random 3..10
jmin      = random 50..500
jmax      = random 500..1500   (must be > jmin)
s1        = random 15..150
s2        = random 15..150     (must satisfy s1+s2 < 1280 для QUIC compatibility)
h1, h2, h3, h4 = random uint32 (each peer has unique header values)
```

### Client URI format

Subscription returns:
```
amneziawg://<base64(WG-INI-config)>?name=Palma#%F0%9F%8C%B4%20%D0%9F%D0%B0%D0%BB%D1%8C%D0%BC%D0%B0
```

happ-desktop / happ-mobile parses `amneziawg://` scheme, decodes config, configures embedded amneziawg-go-client.

WG-INI-config example (base64-encoded):
```ini
[Interface]
PrivateKey = <user_priv>
Address = 10.66.66.42/32
DNS = 1.1.1.1
Jc = 5
Jmin = 50
Jmax = 1000
S1 = 39
S2 = 56
H1 = 1485860389
H2 = 1294232442
H3 = 1810728758
H4 = 489462094

[Peer]
PublicKey = <server_pub>
PresharedKey = <user_psk>
AllowedIPs = 0.0.0.0/0
Endpoint = hiearth.ru:51820
PersistentKeepalive = 25
```

## R4 — XHTTP response chunking (Дуб)

**Митигирует**: «freezing» attack где server response >15-20KB на одном TCP+TLS 1.3 connection с foreign-datacenter IP → middlebox замораживает соединение.

**Подход** (зависит от Xray 26.x flag availability):
1. Прежде всего — проверить через Xray-core docs/source какой config flag контролирует XHTTP response chunking
2. Likely кандидаты:
   - `xhttpSettings.scMaxEachPostBytes` — max chunk size per POST
   - `xhttpSettings.scMaxConcurrentPosts` — increase parallelism so single TCP doesn't accumulate
   - `xhttpSettings.scStreamUpServerSecs` — server-side stream timing
3. Конфигурируем в `cmd/api/xray_sync.go` для `vless-xhttp` inbound:
   ```go
   "xhttpSettings": map[string]any{
       "path": "/",
       "host": "hiearth.ru",
       "mode": "auto",
       "xPaddingBytes": "100-1000",
       "scMaxEachPostBytes": "10000-15000",  // NEW: cap each POST chunk under 15KB
       "scMaxConcurrentPosts": "20-40",      // NEW: split across many TCP connections
   }
   ```

**Best-effort task**: если флаги доступны в Xray 26.x → apply. Если нет → document and defer to upstream Xray support (skip without failure).

## R5 — Mobile operator direct-routes

**Митигирует**: APN-leak loop где cellular юзер'ский traffic к собственному операторскому сервису (mts.ru → MTS billing portal) идёт через Hub → exit-node → обратно через MTS infrastructure. Operator distincts this as "VPN signature".

**Подход**: INSERT 4 entries в `direct_route_services` table (existing table seeded with banks/gov/yandex/vk). Migration 000051 (combined с awg schema):
```sql
INSERT INTO direct_route_services (service_name, domain, plan_id_scope)
SELECT 'МТС', 'mts.ru', NULL  -- NULL = applies to all plans
UNION ALL SELECT 'Tele2', 'tele2.ru', NULL
UNION ALL SELECT 'Мегафон', 'megafon.ru', NULL
UNION ALL SELECT 'Билайн', 'beeline.ru', NULL
ON CONFLICT DO NOTHING;
```

(Точная schema этой table будет verified в implementation phase — может быть другие колонки.)

**Effect**: `biz/happ_routing.go::BuildHappRoutingConfig` уже включает direct_route_services в happ Smart Routing `DirectSites` array → cellular APN trafic идёт **direct** не через tunnel.

## DB schema migration 000051

**One migration covering R7 + R5:**

```sql
-- up.sql
-- ─────────── R7: AmneziaWG per-plan toggle ───────────
ALTER TABLE plans ADD COLUMN amnezia_wg_enabled BOOLEAN NOT NULL DEFAULT FALSE;

-- ─────────── R7: per-user AmneziaWG keys + CPS + IP ───────────
ALTER TABLE users
  ADD COLUMN awg_private_key   TEXT,
  ADD COLUMN awg_public_key    TEXT,
  ADD COLUMN awg_preshared_key TEXT,
  ADD COLUMN awg_cps_params    JSONB,
  ADD COLUMN awg_ip_address    VARCHAR(16);

CREATE UNIQUE INDEX IF NOT EXISTS idx_users_awg_ip
  ON users(awg_ip_address) WHERE awg_ip_address IS NOT NULL;

-- ─────────── R5: mobile operator direct-routes ───────────
INSERT INTO direct_route_services (service_name, domain)
SELECT * FROM (VALUES
  ('МТС',     'mts.ru'),
  ('Tele2',   'tele2.ru'),
  ('Мегафон', 'megafon.ru'),
  ('Билайн',  'beeline.ru')
) AS v(service_name, domain)
ON CONFLICT (domain) DO NOTHING;
```

**Down.sql** — reverse:
```sql
DELETE FROM direct_route_services WHERE domain IN ('mts.ru', 'tele2.ru', 'megafon.ru', 'beeline.ru');
ALTER TABLE users
  DROP COLUMN IF EXISTS awg_private_key,
  DROP COLUMN IF EXISTS awg_public_key,
  DROP COLUMN IF EXISTS awg_preshared_key,
  DROP COLUMN IF EXISTS awg_cps_params,
  DROP COLUMN IF EXISTS awg_ip_address;
ALTER TABLE plans DROP COLUMN IF EXISTS amnezia_wg_enabled;
```

(Conflict resolution `ON CONFLICT (domain)` assumes UNIQUE constraint on `direct_route_services.domain` — verify exists during implementation.)

## Out of Scope

- **Beta sub-project** (R6 per-user SNI rotation) — отдельный spec/plan later if Alpha не решит Tele2 issue
- **AmneziaWG auto-rotation CPS params** (как auto-tuner для Reality SNI) — fixed per-user в MVP
- **Per-user port-hopping для AmneziaWG** (CPS junk packets уже handle DPI, port-hopping избыточен)
- **WireGuard kernel module** (используем userspace amneziawg-go для simplicity)
- **AmneziaWG IPv6 pool** (только IPv4 10.66.66.0/24 в MVP)
- **Scale beyond 254 users on AmneziaWG** (10.66.66.0/24 даёт максимум 254 peer slots) — расширить pool до 10.66.0.0/16 при достижении лимита

## Risks

| Риск | Mitigation |
|---|---|
| **happ может не support `amneziawg://` URI scheme** | Verify happ docs during T7. Fallback: provide WG `.conf` file download endpoint + manual import |
| **amneziawg-go binary download URL unstable** | Pin to specific GitHub release tag (e.g. v0.2.3); validate SHA256 before install |
| **IP pool 10.66.66.0/24 exhaustion** | 254 user limit. Future migration extends to 10.66.0.0/16. Document threshold |
| **CPS params validation** | Server may reject malformed configs. Test with known-good CPS values (Amnezia docs) before per-user random generation |
| **Xray 26.x R4 flags missing** | Best-effort task. If flag not in Xray — document deferral; не blocking для AmneziaWG ship |
| **Conflict с existing Hysteria2 :50443** | AmneziaWG на :51820 — different port. ufw rules independent |
| **AmneziaWG `wg-quick` not installed** | We use `amneziawg-go` userspace binary — doesn't need kernel module or wg-quick. Bundled |
