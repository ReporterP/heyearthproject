> По пунктам:

> **1. Поддержка автоплатежей в CMS.**
>
> CMS не используется — сайт самописный (backend на Go, фронтенд на
> React, база PostgreSQL). Интеграция с ЮKassa реализована напрямую
> через ваш REST API v3 (https://api.yookassa.ru/v3) без посредников.
>
> Автоплатежи реализованы следующим образом:
> - При первом платеже передаём `save_payment_method: true` — карта
>   сохраняется в ЮKassa, возвращается `payment_method_id`.
> - Сохранённый `payment_method_id` записывается в нашу БД
>   (`users.saved_payment_method` + отдельная таблица
>   `saved_payment_methods` с last4, card_type, issuer).
> - Для последующих автоплатежей отправляем POST /v3/payments с
>   `payment_method_id` (без confirmation) — списание происходит без
>   участия пользователя.
> - При неуспешной попытке запускается retry-логика (1/2/3 попытки с
>   интервалами 24ч/72ч/168ч) с email-уведомлениями и grace period
>   3 дня для сохранения доступа на время ретраев.
>
> Уведомления от ЮKassa (webhook) принимаются на
> `https://hiearth.ru/api/v1/webhooks/yookassa`. События:
> `payment.succeeded`, `payment.canceled`, `refund.succeeded`,
> `payment.waiting_for_capture`. Дополнительно действует fallback
> cron (каждые 5 мин), опрашивающий все pending-платежи через
> `GET /v3/payments/{id}` — для устойчивости к потерянным webhook'ам.
>
> **2. Скриншоты отвязки карты.**
>
> Функция отвязки доступна в личном кабинете пользователя на странице

## Дополнительные детали, которые могут потребоваться

### Конфигурация вебхука (для админов ЮKassa при проверке)

- URL: `https://hiearth.ru/api/v1/webhooks/yookassa`
- Метод: POST
- Авторизация: двухуровневая
  1. IP whitelist против диапазонов ЮKassa из документации
  2. Повторный `GET /v3/payments/{id}` для верификации факта платежа
     даже если тело webhook подделано

### Флоу recurring

```
1. Пользователь выбирает тариф на hiearth.ru/payment
2. Отмечает checkbox "Сохранить карту для автопродления"
3. Redirect или embedded widget → оплата → webhook payment.succeeded
4. Backend сохраняет payment_method.id в users.saved_payment_method
5. За 30 дней до окончания подписки запускается cron auto-renew
6. POST /v3/payments с payment_method_id, capture=true,
   save_payment_method отсутствует (карта уже сохранена)
7. На succeeded → подписка продлевается на 30 дней, email юзеру
8. На failed → retry цепочка (3 попытки × 24/72/168ч) + email + grace
```

### Безопасность хранения

- Сам номер карты / CVC не хранится нигде на нашей стороне —
  только `payment_method_id` (токен ЮKassa) + отображаемая часть
  (`last4`, `card_type`) для UI.
- Секретный ключ ЮKassa хранится в `app_settings` таблице в БД
  (защищённый доступ только у admin).
- Подключение к api.yookassa.ru — HTTP Basic Auth с
  Idempotence-Key на каждом POST.
