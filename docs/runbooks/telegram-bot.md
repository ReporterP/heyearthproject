# Runbook: Telegram-бот для пользователей

Второй бот HiEarth (не бот алертов): кабинет в Telegram (Mini App), уведомления, поддержка, новости и канал, оплата подписки звёздами. План: `docs/superpowers/plans/2026-11-17-telegram-bot-plan.md`. Спецификация экранов: `site/design-system/hiearth-canon/spec/12-telegram.md`, 08 §8.6–8.7.

## Как устроено

- **Сеть.** Hub не всегда достаёт до Telegram. Все вызовы Bot API идут общим маршрутом `telegram` (`cmd/api/alerts.go` → `internal/telegram.Route`): сначала напрямую, при сбое — через локальный SOCKS здорового exit; после сбоя прямой путь пропускается 10 минут. Обновления — long polling `getUpdates` (вебхуков нет).
- **Один экземпляр.** Опрос бота пользователей, опрос бота алертов (ответы владельца в поддержку) и очередь исходящих (`tg_outbox`) работают под advisory lock Postgres (`tgbot.go`, ключи `0x7467000N`). Offset хранится в `app_settings` (`tg_bot_offset`, `alert_telegram_offset`).
- **Очередь.** Уведомления, ответы поддержки и рассылка новостей — строки `tg_outbox` (одна на `(user, kind, ref)`), ≤ 25 сообщений/с и 1/с на чат. 429 → пауза `retry_after` (до 1 минуты на всю очередь, строка ждёт свой `next_at`); 403 «blocked» → `users.tg_blocked`.
- **Настройки** (`app_settings`, пишутся только через админку «Telegram-бот»): `tg_bot_token` (только запись), `tg_bot_username`, `tg_channel_id`, `tg_stars_rub` (курс: рублей за 1 ⭐; пусто — оплата звёздами выключена).
- **Картинки** поддержки и новостей: `$UPLOADS_DIR` (по умолчанию `/opt/heyearth/state/uploads/{support,news}`), вне веб-корня. Картинки поддержки отдаются только владельцу обращения и админу, новостей — всем.

## Бот без Mini App

Всё повседневное — прямо в чате: `/menu` (и `/start`) присылает меню на кнопках — 💳 Баланс, 📅 Подписка (вкл/выкл автопродления), 🔌 Подключить, 🎁 Друзьям, ⭐ Оплатить, 💬 Поддержка, 📰 Новости, ⚙️ Настройки; раздел заменяет сообщение меню (`editMessageText`), команды присылают раздел новым сообщением (`tgbot_menu.go`). Новичок создаёт HiEarth ID или входит по ID прямо в чате (сообщение с ID бот сразу удаляет; аккаунт с паролем — через Mini App). Mini App остаётся: кнопка меню «Кабинет» и «🌐 Кабинет целиком».
**«📤 Отправить другу»** работает через inline-режим: владелец включает его в @BotFather → `/setinline` (подсказка, например «Пригласить друга»), затем «Проверить» в админке — бот запомнит флаг (`tg_bot_inline`, обновляется и сам раз в 30 минут). Без inline-режима кнопка открывает обычное окно «Поделиться» Telegram.

## Оплата внутри Telegram — только звёзды

Правила Telegram (Bot Platform Developer Terms §6.2, FAQ core.telegram.org/bots/payments-stars): цифровые услуги внутри бота и Mini App продаются **только за Telegram Stars**, независимо от сайта и платёжных систем вне Telegram; крипта (и TON) запрещена; иначе бот перестают показывать на телефонах, вплоть до бана. Поэтому:
- в боте и Mini App нет ссылок на оплату на сайте, ЮKassa, карт; на сайте ЮKassa и кошелёк работают как раньше;
- тариф за звёзды: цена = ⌈цена в ₽ / курс⌉; один платёж — один срок тарифа (дни добавляются к текущей подписке); дешевле текущего — только после его конца;
- `pre_checkout_query` принимается только для привязанного аккаунта, доступного тарифа и показанной цены; `successful_payment` включает подписку один раз на `telegram_payment_charge_id` (`stars_payments`), при сбое звёзды возвращаются автоматически и приходит алерт;
- `/paysupport` обязателен (§6.2.1) — ведёт в поддержку;
- возврат вручную: админка «Telegram-бот» → «Оплата звёздами» → «Вернуть звёзды» (право `payments.refund`). Подписку возврат не сокращает.

## Настройка (владелец)

1. @BotFather → `/newbot` → имя «HiEarth» → username (например `hiearth_app_bot`). Токен — в админку «Telegram-бот», «Сохранить»: сервер проверит `getMe` и поставит меню команд, кнопку «Кабинет» (Mini App `https://<сайт>/tg`) и описание.
2. Создать публичный канал, добавить бота администратором (публикация, редактирование, удаление), вписать `@имя` канала, «Проверить канал».
3. Задать курс звёзд («1 ⭐ = N ₽»).
4. Бот алертов (раздел «Алерты») — туда же приходят новые обращения в поддержку; ответ на уведомление (reply) уходит человеку. В групповом чате алертов принимаются ответы только его администраторов.

## Проверка

```bash
go run ./cmd/deploy --ssh 'journalctl -u heyearth-api -n 50 --no-pager | grep -E "telegram|tg-|stars|news|support"'
```
- в журнале: `[telegram] бот пользователей: опрос обновлений и очередь сообщений запущены`; без токена опрос молча ждёт;
- админка «Telegram-бот» → «Проверить»: `@бот отвечает (напрямую|через exit)`;
- в Telegram: `/start` → «Открыть кабинет» → кабинет открылся под своим аккаунтом.

## Сбои

| Симптом | Что смотреть |
|---|---|
| Бот не отвечает | журнал `tg-user-poller`: 401 — токен неверен; 409 — у бота висит вебхук (сохраните токен ещё раз — сервер делает `deleteWebhook`); «работает в другом экземпляре» — второй API держит замок |
| Сообщения не уходят | `SELECT status, error, count(*) FROM tg_outbox GROUP BY 1,2` — `failed`/`blocked`; маршрут: «Проверить» в админке |
| Mini App: «Не удалось проверить вход» | токен сменили после открытия кабинета, или `initData` старше 12 ч — закрыть и открыть кабинет из бота |
| Оплата звёздами не включила подписку | `SELECT * FROM stars_payments ORDER BY id DESC LIMIT 5` — `refunded`/`failed` с причиной; алерт `stars-payment-N` |
| Новость не ушла в канал | у новости в админке ошибка «Канал: …»; «Проверить канал» — бот должен быть администратором с правом публикации |
