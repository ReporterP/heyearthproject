# Xray Binary for HeYearth Installer

Place the following files here before building the installer:

1. `xray.exe` — Download from https://github.com/XTLS/Xray-core/releases
2. `geoip.dat` — (optional) IP geolocation database
3. `geosite.dat` — (optional) Domain routing database

These files will be bundled into the Windows installer.
