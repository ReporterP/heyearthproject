# Релизы приложения

Здесь скрипт `scripts/release.py` автоматически ведёт учёт выложенных версий:

- **releases.json** — список версий по платформам (android, windows, …). Не редактируйте вручную.
- **{platform}_{version}.txt** — заметка о каждом успешном релизе (дата, платформа).

Версия берётся из `pubspec.yaml` (в корне проекта). При выкладке `python3 scripts/release.py --android -v 1.2.6` скрипт проверит, что 1.2.6 совпадает с pubspec и ещё не была выложена для этой платформы.
